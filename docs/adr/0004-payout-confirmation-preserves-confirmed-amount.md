# 지급 확인 당시 금액은 원본 정정 후에도 보존한다

직원 수당의 지급 확인 후 출퇴근이나 완료 콜을 정정하면 계산 금액이 달라질 수 있다. 지급 확인 당시 금액과 확인 기록은 보존하고, 현재 계산 금액이 달라지면 재확인 필요로 표시하여 정산 담당자가 차이와 사유를 확인하게 한다. 단순한 지급완료 표시를 현재 계산 금액에 그대로 붙이면 과거에 확인한 금액을 알 수 없으므로 이 방식을 택한다. 이 기록은 실제 송금·분할 지급 전표가 아니다. 월 명세서는 마감 전에는 미확정 계산 결과, 마감 후에는 해당 마감 버전의 확정 금액을 사용한다.
