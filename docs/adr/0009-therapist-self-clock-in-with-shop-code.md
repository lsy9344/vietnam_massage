# Therapist는 매장 화면의 출근 코드로 직접 출퇴근을 찍는다

Therapist는 자기 휴대폰으로 직접 출퇴근을 찍고, 이때 매장 화면(TV 현황판, 카운터)에 보이며 1분마다 바뀌는 4자리 출근 코드를 입력해야 한다. 출퇴근 시각은 만근 인정과 만근수당으로 이어지므로 집에서 찍는 것을 막아야 한다. QR은 아이폰에서 홈 화면 웹앱과 카메라로 연 사파리의 로그인이 따로라서, GPS는 실내 오차와 위치 조작 앱 때문에, 매장 와이파이 주소는 인터넷 주소가 자주 바뀌어서, 카운터 승인은 카운터 일이 늘어서 택하지 않았다. 코드는 시각으로 계산하므로 DB를 깨우지 않는다. 휴대폰이 꺼진 경우처럼 Therapist가 찍지 못하면 운영팀이 대신 입력한다.
