# 미완료 콜은 확인과 사유를 남겨 예외 마감한다

마감 대상 운영월의 예약·사용중·청소중 콜은 확인 대상 목록으로 제시하고 사유를 남기면 예외 마감할 수 있다. 남아 있는 예약을 놓치지 않으면서 마감을 위해 허위 방문완료를 만들지 않도록, 상태를 자동 변경하거나 모두 계산 오류로 처리하는 대신 이 방식을 택한다. 방문완료·취소·노쇼는 미완료 예외 목록에서 제외한다. 계산 오류와 지급 재확인 미처리는 별도의 확정 차단 조건이며 미완료 예외 사유로 우회할 수 없다. 확인 대상·사유·행위자는 마감 버전과 연결해 보존하고 기존 금액 반영 규칙은 유지한다.
