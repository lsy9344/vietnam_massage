# 02 — 고객 검색과 방문 이력

**What to build:** 카운터나 관리자가 콜 원장의 고객 검색에 이름, 연락처, 메모나 과거 콜의 고객/메모, 비고를 치면 방문 이력이 열린다. 한 줄이 콜 한 건이다. 날짜를 누르면 그 날 원장으로 간다. 잠긴 달도 찾아진다.

**Blocked by:** 01 — 고객 기록과 콜 연결

**Status:** done

- [x] 검색 칸의 보이는 라벨은 "고객 검색"이다.
- [x] 검색은 고객의 이름, 연락처, 메모와 콜의 고객/메모, 비고를 운영월을 넘어 찾는다. 잠긴 달의 콜도 조회된다.
- [x] 빈 검색어는 결과를 내지 않는다.
- [x] 입력 후 잠시 뒤에 후보가 뜬다. 후보는 고객/메모와 최근 방문일을 보여 주고, 화살표와 Enter로 고른다.
- [x] 고객 후보는 그 고객으로 연결된 콜을 연다. 연결되지 않은 일치는 같은 고객/메모끼리 묶이고, 그 묶음의 콜을 연다.
- [x] 이력의 한 줄은 콜 한 건이며 날짜, 예약시각, 코스, Therapist, 상태, 고객/메모가 보인다.
- [x] 방문완료가 위에 온다. 같은 상태 안에서는 늦은 날짜, 그다음 늦은 예약시각이 위에 온다. 예약, 노쇼, 취소도 상태를 적어 보여 준다.
- [x] 날짜를 누르면 그 날의 콜 원장으로 간다.
- [x] 검색어는 주소에 남고, 뒤로 가면 결과와 스크롤이 돌아온다.
- [x] 일치가 없으면 없다는 말과 함께, 이름이나 번호의 일부를 다시 쳐 보라는 한 줄이 나온다.
- [x] 잠긴 달의 콜을 찾았어도 그 달의 수정은 지금처럼 거절된다.
- [x] 새 문구는 한국어와 베트남어가 함께 있다.
- [x] 콜 서비스 테스트가 콜 한 건이 한 줄인 것, 방문완료 우선, 예약·노쇼·취소가 남는 것, 잠긴 달의 조회를 반환값으로 확인한다.
