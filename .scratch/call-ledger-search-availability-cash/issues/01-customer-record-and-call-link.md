# 01 — 고객 기록과 콜 연결

**What to build:** 카운터나 관리자가 콜 원장에서 고객을 만들고, 이름, 연락처, 메모를 고친 뒤, 그 고객을 콜에 연결할 수 있다. 연결해도 그 콜의 고객/메모는 그대로다. 같은 연락처가 있어도 고르기 전에는 붙지 않는다. 새 메뉴는 없다.

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 카운터가 콜 원장에서 이름, 연락처, 메모를 가진 고객을 만들 수 있다.
- [x] 카운터가 그 세 필드를 고칠 수 있다.
- [x] 연락처는 고유하지 않다. 같은 연락처의 고객이 둘 있어도 자동으로 콜에 붙지 않고, 사람이 고른 고객만 연결된다.
- [x] 고객을 콜에 연결하거나 연결을 해제해도 그 콜에 적힌 고객/메모는 바뀌지 않는다.
- [x] 잠긴 운영월의 콜 저장은 지금과 같이 거절된다.
- [x] 고객을 만들거나 고친 일, 콜에 연결한 일은 관리자가 지금 보는 감사 로그에 남는다. 감사 화면은 새로 만들지 않는다.
- [x] 고객 삭제, 병합, 가져오기는 없다.
- [x] 새 문구는 한국어와 베트남어가 함께 있다.
- [x] 콜 서비스 테스트가 생성, 수정, 연결, 자동 연결이 없는 것, 고객/메모가 유지되는 것, 잠긴 달의 저장 거절을 반환값으로 확인한다.
