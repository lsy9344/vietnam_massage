# 05 — 객실, 실시간, TV의 표시 종료

**What to build:** 객실 카드, 실시간, TV가 그 콜의 표시 종료를 그대로 보여 준다. 종료가 가까운지도 그 시각으로 본다. 바닥 화면은 고객 검색이나 지출 입력을 받지 않는다.

**Blocked by:** 04 — 실제입장과 표시 종료

**Status:** done

- [x] 객실 상태의 종료 예상은 그 콜의 표시 종료와 같다.
- [x] 실시간과 TV는 그 객실 상태를 그려서 같은 표시 종료를 보여 준다.
- [x] 남은 시간과 종료 임박은 이 표시 종료를 기준으로 하고, 화면이 코스 길이를 다시 더하지 않는다.
- [x] 객실, 실시간, TV에는 고객 검색, 고객/메모 수정, 지출 입력이 없다.
- [x] 객실 상태 테스트는 종료 예상이 콜 서비스가 이미 돌려준 표시 종료와 같은지만 확인한다. 3시 20분과 4시의 양보 계산을 여기서 다시 검증하지 않는다.

## Comments

- 2026-10-13: 객실 상태의 종료 예상은 콜 서비스가 돌려준 표시 종료다. 코스 정책이 없어도 그 시각을 비우지 않는다. 실시간과 TV는 `RoomStatusCard`로 그 상태를 그린다.
