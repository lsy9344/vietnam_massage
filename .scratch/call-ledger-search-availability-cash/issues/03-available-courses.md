# 03 — 가능 코스

**What to build:** 카운터나 관리자가 콜 원장에서 시각을 고르면 활성 Therapist 전원이 한 표로 나온다. 그 시각에 가능한 코스가 글자로 보이고, 가능한 코스를 누르면 새 행의 예약시각, Therapist, 코스가 채워진다. 목록은 저장을 막지 않는다.

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 접혀 있으면 "가능 코스"와 시각 선택만 보인다. 펼치면 표다. 칸은 Therapist, 출근, 이 시각, 다음 예약, 가능한 코스다.
- [x] 대상은 활성 Therapist뿐이다. 귀케어와 운영팀은 없다. 출근하지 않은 사람도 목록에 있고, 출근은 글자로만 붙는다.
- [x] 점유는 예약시각부터 그 운영월 코스 정책의 길이까지다. 끝나는 시각과 다음 예약시각이 같으면 다음 예약은 가능하다.
- [x] 노쇼와 취소는 점유하지 않는다. 예약, 사용중, 청소중, 방문완료는 그 구간만 점유한다. Therapist 1과 Therapist 2 배정이 둘 다 그 사람을 점유한다.
- [x] 점유 중이면 이 시각 칸은 "불가 · HH:mm부터"처럼 비는 예약시각을 글로 말한다. 비어 있으면 다음 예약시각과 빈 분이 보인다.
- [x] 다음 예약이 없으면 빈 분은 그날 마지막 시간 슬롯의 끝까지다. 코스는 그 빈 분에 길이가 들어갈 때만 가능하다.
- [x] 두 번째 Therapist가 필요한 코스는, 그 Therapist가 코스 길이만큼 비어 있고 다른 활성 Therapist도 같은 구간 동안 한 명 이상 비어 있을 때 가능하다. 길이와 두 번째 Therapist 필요 여부는 코스 정책에서 온다.
- [x] 가능한 코스는 분과 가능이 적힌 버튼이다. 불가 코스는 버튼이 아니고 분과 불가가 적힌 글자다. 버튼은 줄이 바뀌고 잘리지 않는다.
- [x] 가능한 코스를 누르면 새 행의 예약시각, Therapist, 코스가 채워지고, 그 자리에서는 저장하지 않는다. 목록에서 불가인 긴 코스도 원장에 적어 저장할 수 있다.
- [x] Therapist가 없으면 그 시각에 볼 사람이 없다는 말과, 다음에 무엇을 볼지 한 줄이 나온다.
- [x] 키보드 순서는 시각 선택, 펼치기, 가능 버튼, 그다음 원장이다.
- [x] 2시에 90분 콜이 있으면 3시는 불가이고 3시 30분부터 가능하다. 3시에 다음 예약이 4시면 60분 코스는 가능하고 90분과 120분 코스는 불가다. 3시에 끝나는 콜은 3시 시작을 막지 않는다.
- [x] 새 문구는 한국어와 베트남어가 함께 있다. 기존 토큰과 원장 칸 높이는 유지되고, 새 컨트롤의 누르는 영역은 44px 이상이다.
- [x] 콜 서비스 테스트가 위 점유, 맞닿음, 코스 길이, 두 번째 Therapist, 두 배정의 점유를 반환값으로 확인한다. 화면 테스트는 그 글자를 그대로 보여 주는지만 확인한다.
