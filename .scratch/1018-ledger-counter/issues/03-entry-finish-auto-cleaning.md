# 03: 입장·종료·청소 끝·종료 취소, 결제 배지, 자동 청소 중

**What to build:** 행 버튼을 `입장 → 종료 → 청소 끝(+종료 취소)`으로 바꾸고, 상태 칩이 같은 시각 규칙을 따르게 한다. 결제 배지를 붙이고, 읽을 때 정리하는 자동 청소 중을 넣는다. (스펙 D11–D15)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 입장은 사용중으로 바꾸고 실제 입장 = 지금(분 단위)으로 저장한다. `entryClock`의 10분 반올림을 없앤다.
- [ ] 종료는 청소중으로 바꾸고 실제 종료 = 지금으로 저장한다. 청소 끝은 방문완료로 바꾼다. 종료 취소는 사용중으로 되돌리고 실제 종료를 지운다. 확인 창은 없다.
- [ ] 상태 칩으로 바꿀 때 D11 규칙대로 입장·종료 시각을 채우거나 지운다. 예약으로 되돌리면 둘 다 지운다.
- [ ] 입장·종료 시각을 누르면 그 자리에서 고칠 수 있다.
- [ ] 결제 배지는 결제수단이 있으면 `결제완료`, 없으면 `결제 미확인`이다. 누르면 수단 목록이 뜨고, 고르는 즉시 저장된다. 상태는 바꾸지 않는다. 패널의 "결제 완료 → 방문완료" 동작을 없앤다.
- [ ] 자동 청소 중: 원장·객실·실시간·TV·가능 판정이 그 영업일을 읽기 전에, 표시 종료를 지난 사용중 콜을 청소중 + 실제 종료 = 표시 종료로 저장한다. 감사 기록은 "자동 종료"다. 운영월이 잠겼거나 입장이 없으면 건드리지 않는다. 같은 요청이 동시에 와도 두 번 쓰지 않는다.
- [ ] "종료 확인 필요" 안내와 overrun 점유 계산을 없앤다.
- [ ] ADR 0008(자동 청소 중이 "자동 완료 금지"를 대체)을 쓰고 `CONTEXT.md`를 고친다.
- [ ] 객실 화면의 청소중 표시가 종료·종료 취소·청소 끝을 따라간다.
- [ ] 단위 테스트(시각 규칙, 자동 정리, 점유 끝)와 E2E(버튼 흐름, 종료 취소, 자동 청소 중)를 넣는다. ko·vi 문구를 넣는다.
