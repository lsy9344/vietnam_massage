# 02: 두 줄 원장 목록

**What to build:** 흐름별 한 줄 표(`call-ledger-list.tsx`)를 예약 하나 = 두 줄 행의 시간순 목록으로 바꾼다. 칸 안 목록(Therapist·객실)과 행 클릭 패널을 붙인다. 버튼 규칙은 기존 것을 그대로 쓰고, 03에서 바꾼다. (스펙 D3–D10)

**Blocked by:** 01

**Status:** done

- [x] 목록 하나를 예약 시각순으로 보인다. "지금 이용 중 / 예약" 묶음을 없앤다. 하단 "완료·취소·노쇼 N" 접기 영역은 유지한다.
- [x] 윗줄은 예약 시각 · 입장 → 종료(`미입장` / 흐린 `예상 HH:MM` / 진한 실제 종료) · 상태 칩 · 주 버튼이다. 아랫줄은 경로·예약자 · 코스 · Therapist ▾ · 객실 ▾ · 결제 배지 자리다.
- [x] `지금 HH:MM` 구분선을 넣는다. 예약 상태인데 예약 시각이 지났으면 `N분 늦음`을 붙인다.
- [x] Therapist 칸 목록: 가능한 사람이 위(지금 가능 → 오늘 완료 적은 순)이고, 불가한 사람은 경고 후 고른다. 미지명 행에서 고르면 배정된다.
- [x] 객실 칸 목록은 빈 객실이 먼저다. 칸 안 목록은 키보드로 열고 닫고 고를 수 있다.
- [x] 행의 나머지를 누르면 편집 패널이 열린다. 패널 입장 묶음에 상세 시각 여섯 개를 보인다(D10).
- [x] 일행 행은 왼쪽 세로 막대로 묶는다. 머리 줄의 전체 입장·1명 추가를 유지한다.
- [x] 경로·예약자가 없는 옛 콜은 고객 이름, 그것도 없으면 고객/메모 첫 줄을 보인다.
- [x] 1280·1024px에서 패널을 열어도 가로 스크롤이 0이다. 600px 미만은 같은 두 줄 행이고 읽기 전용이다.
- [x] 키보드 동선(↑↓, Enter, Esc, N)을 유지한다. 운영월이 잠기면 칸과 버튼도 잠긴다.
- [x] 깨지는 E2E는 새 동선으로 다시 쓴다. ko·vi 문구를 넣는다.

## Comments

- 2026-10-19 구현(브랜치 feat/1018-ledger-rework).
  - 목록: `call-ledger-list.tsx`가 표 대신 `ol` 두 줄 행이다. 규칙은 `ledger-flow.ts`의 순수 함수로 두었다: `ledgerTimeline`(열린 콜 한 목록 + 하단 완료·취소·노쇼), `nowDividerIndex`·`lateMinutes`(영업일 자정 넘김 포함), `ledgerEndView`(D4), `ledgerWhoLabel`(D10 대체: 예약자명 → 연결 고객 이름 → 고객/메모 첫 줄), `therapistPickList`, `roomPickList`. `ledgerFlowSections`와 흐름 묶음 문구는 지웠다. 목록 이름은 "콜 원장 목록"이다.
  - `지금 HH:MM`·`N분 늦음`은 보고 있는 날짜가 영업일 오늘일 때만 보인다(가정). 시계는 붙은 뒤 읽고 30초마다 다시 읽는다(서버 렌더와 첫 화면을 맞추려고).
  - 칸 안 목록(`ledger-cell-picker.tsx`): body에 뜨는 listbox, Enter·Space로 열고 ↑↓·Home·End·Enter·Esc. 위치 재기는 편집 패널 선택칸의 `measureListboxPosition`을 같이 쓴다. Therapist 목록은 열 때마다 그 콜의 시각으로 가능 판정을 받는다. 그 콜 자신의 점유를 빼려고 `listTherapistAvailability`에 `excludeCallId`를 더했다(콜 수는 그대로 센다). 위 묶음은 출근해 있고 그 코스가 가능한 사람(완료 적은 순)이고, 출근 전·퇴근·불가한 사람은 아래다(리뷰 반영: 출근 전 사람이 위로 오던 것을 고침, 빠른 예약 D23과 같은 뜻). 불가한 사람은 빠른 예약의 "경고 확인 후 배정" 창을 거친다. 그 달 정책이 없어 가능 판정에 없는 코스는 시각만으로 본다. 객실 목록의 "빈 객실"은 기존 `freeRoomOptions` 뜻(지금 사용중·청소중 콜이 쓰지 않는 객실)이다(가정). 두 목록 끝에 "미지명"/"미배정"을 두어 비울 수 있다.
  - 결제 배지는 02에서는 읽기 전용이다(누르는 동작은 D12, 티켓 03). 주 버튼(입장·결제)과 입장 10분 맞춤은 그대로다.
