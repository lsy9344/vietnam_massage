# 02: 두 줄 원장 목록

**What to build:** 흐름별 한 줄 표(`call-ledger-list.tsx`)를 예약 하나 = 두 줄 행의 시간순 목록으로 바꾼다. 칸 안 목록(Therapist·객실)과 행 클릭 패널을 붙인다. 버튼 규칙은 기존 것을 그대로 쓰고, 03에서 바꾼다. (스펙 D3–D10)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 목록 하나를 예약 시각순으로 보인다. "지금 이용 중 / 예약" 묶음을 없앤다. 하단 "완료·취소·노쇼 N" 접기 영역은 유지한다.
- [ ] 윗줄은 예약 시각 · 입장 → 종료(`미입장` / 흐린 `예상 HH:MM` / 진한 실제 종료) · 상태 칩 · 주 버튼이다. 아랫줄은 경로·예약자 · 코스 · Therapist ▾ · 객실 ▾ · 결제 배지 자리다.
- [ ] `지금 HH:MM` 구분선을 넣는다. 예약 상태인데 예약 시각이 지났으면 `N분 늦음`을 붙인다.
- [ ] Therapist 칸 목록: 가능한 사람이 위(지금 가능 → 오늘 완료 적은 순)이고, 불가한 사람은 경고 후 고른다. 미지명 행에서 고르면 배정된다.
- [ ] 객실 칸 목록은 빈 객실이 먼저다. 칸 안 목록은 키보드로 열고 닫고 고를 수 있다.
- [ ] 행의 나머지를 누르면 편집 패널이 열린다. 패널 입장 묶음에 상세 시각 여섯 개를 보인다(D10).
- [ ] 일행 행은 왼쪽 세로 막대로 묶는다. 머리 줄의 전체 입장·1명 추가를 유지한다.
- [ ] 경로·예약자가 없는 옛 콜은 고객 이름, 그것도 없으면 고객/메모 첫 줄을 보인다.
- [ ] 1280·1024px에서 패널을 열어도 가로 스크롤이 0이다. 600px 미만은 같은 두 줄 행이고 읽기 전용이다.
- [ ] 키보드 동선(↑↓, Enter, Esc, N)을 유지한다. 운영월이 잠기면 칸과 버튼도 잠긴다.
- [ ] 깨지는 E2E는 새 동선으로 다시 쓴다. ko·vi 문구를 넣는다.
