# 04: 상태 카드, Therapist 현황 줄, 하루 수납 이번 달 권한

**What to build:** 원장 머리의 상태 건수를 카드 7개로 바꾸고, `1+4` 띠를 Therapist 현황 줄로 바꾼다. 하루 수납 화면의 이번 달 숫자는 관리자·정산 담당에게만 보낸다. (스펙 D16–D18)

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 상태 카드 7개를 한 줄에 둔다. 전체 숫자를 가장 크게 하고 design.md 요약 카드 토큰을 쓴다. 누르는 동작은 지금 그대로다. 좁은 폭에서는 줄을 넘겨 감싼다.
- [ ] 현황 카드에는 번호 · 완료(청소중·방문완료) · 남은 예약 · 지금 상태(지금 가능 / 사용 중 / 출근 전 / 퇴근) · 다음 시각(`~19:00 120분`, `종료 예상 18:30`, `18:00`)을 보인다.
- [ ] 정렬은 하나만 고른다(지금 가능 순 기본 / 완료 적은 순 / 남은 예약 적은 순 / 번호순). 카드를 누르면 그 Therapist를 미리 고른 빠른 예약이 열린다. 카드 안 작은 버튼으로 원장을 그 Therapist의 콜만 보이게 거른다. 줄을 접고 펼 수 있고, 기기에 기억한다.
- [ ] 끝에 `미지명 N`을 둔다. 객실·청소 정보는 넣지 않는다.
- [ ] 하루 수납 "이번 달" 숫자는 administrator·settlement_manager에게만 서버에서 넣는다. 카운터 계정의 HTML에는 그 숫자가 없다.
- [ ] 조각 1 전체 검증을 한다. tsc, 단위 테스트, 운영 빌드 E2E 직렬 실행(알려진 실패와 비교)을 돌린다. 운영 DB 마이그레이션과 프리뷰 배포는 사용자 확인 뒤에 한다.
