# 06: 미지명 자리와 근무표 출근 예정 시각

**What to build:** 그 시각의 자리 수와 남은 자리를 서버에서 계산해 빠른 예약 ①에 보인다. 넘치면 경고 후 예약하게 한다. 근무표에 출근 예정 시각 입력을 더하고, 가능 판정이 이 시각을 쓰게 한다. (스펙 D24–D28)

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 자리 계산: 손님 1명 = 1자리, D = 2자리다. 미지명은 [시각, 시각+코스) 동안 자리를 잡는다. 남은 자리는 구간 전체의 최소값이다. 근무 판단은 출근 기록, 근무표 근무 + 출근 예정 시각, 퇴근으로 한다.
- [ ] ①에 `HH:MM 남은 자리 n / N`을 보인다. 담은 손님이 넘치면 경고를 보이고 `그래도 예약` 확인 창(기존 경고 후 배정과 같은 모양)을 띄운다. 지명 목록은 막지 않는다.
- [ ] 원장 Therapist 칸에서 미지명 콜에 배정하면 남은 자리가 맞게 다시 계산된다(이중으로 빠지지 않음).
- [ ] 근무표에 출근 예정 시각을 선택 입력으로 더한다. 지난주 복사가 이 시각도 복사한다. 출근 전에는 이 시각 전을 불가로 보이고(`18:00부터`), 출근 기록이 생기면 그 시각을 기준으로 한다.
- [ ] 현황 줄의 `출근 전 · 18:00`이 이 시각을 보인다.
- [ ] 단위 테스트(고객 예시: 10명, 미지명 4, 지명 3 → 남은 3 / D코스 / 90분 걸침 / 배정 전환)와 E2E를 넣는다.
