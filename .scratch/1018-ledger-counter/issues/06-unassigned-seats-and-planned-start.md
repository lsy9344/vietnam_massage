# 06: 미지명 자리와 근무표 출근 예정 시각

**What to build:** 그 시각의 자리 수와 남은 자리를 서버에서 계산해 빠른 예약 ①에 보인다. 넘치면 경고 후 예약하게 한다. 근무표에 출근 예정 시각 입력을 더하고, 가능 판정이 이 시각을 쓰게 한다. (스펙 D24–D28)

**Blocked by:** 05

**Status:** done

- [x] 자리 계산: 손님 1명 = 1자리, D = 2자리다. 미지명은 [시각, 시각+코스) 동안 자리를 잡는다. 남은 자리는 구간 전체의 최소값이다. 근무 판단은 출근 기록, 근무표 근무 + 출근 예정 시각, 퇴근으로 한다.
- [x] ①에 `HH:MM 남은 자리 n / N`을 보인다. 담은 손님이 넘치면 경고를 보이고 `그래도 예약` 확인 창(기존 경고 후 배정과 같은 모양)을 띄운다. 지명 목록은 막지 않는다.
- [x] 원장 Therapist 칸에서 미지명 콜에 배정하면 남은 자리가 맞게 다시 계산된다(이중으로 빠지지 않음).
- [x] 근무표에 출근 예정 시각을 선택 입력으로 더한다. 지난주 복사가 이 시각도 복사한다. 출근 전에는 이 시각 전을 불가로 보이고(`18:00부터`), 출근 기록이 생기면 그 시각을 기준으로 한다.
- [x] 현황 줄의 `출근 전 · 18:00`이 이 시각을 보인다.
- [x] 단위 테스트(고객 예시: 10명, 미지명 4, 지명 3 → 남은 3 / D코스 / 90분 걸침 / 배정 전환)와 E2E를 넣는다.

- 2026-10-19 구현(브랜치 feat/1018-ledger-rework, 7fee66a 위). 구조는 `src/modules/calls/README.md`의 "1018 Ticket 06"에 적었다. 새 마이그레이션은 없다(출근 예정 시각 칸은 티켓 01에서 운영 DB까지 들어가 있다).
  - 자리: 순수 모듈 `seat-capacity.ts`(`seatTimeline`, `seatShortage`). 서버 `listTherapistAvailabilityWithSeats`가 가능 판정과 같은 조회로 고른 시각부터 가장 긴 코스까지의 자리 점(자리 수, 남은 자리, 일하면서 비어 있는 Therapist)을 계산하고, 빠른 예약 ①이 `HH:MM 남은 자리 n / N`과 넘침 판정에 쓴다. DB 조회는 늘지 않는다.
  - 경고: 담기는 막지 않고, 넘치면 담은 손님 목록에 `자리가 모자랍니다: …`를 보인다. `그래도 예약` 확인 창은 ② 고객으로 넘어갈 때(다음·단계 버튼) 한 번 묻는다. 리뷰에서 "담을 때만 물으면 담은 뒤 시각을 바꿔 넘친 경우를 놓친다"는 지적을 받아 담을 때가 아니라 넘어갈 때로 옮겼다. 그래서 칩 경고 창(티켓 21)은 그대로다.
  - 근무표: 근무 예정 칸에만 출근 예정 시각(`type="time"`, 선택)을 둔다. 휴무·미입력으로 바꾸면 지운다. 시각만 바꿔도 감사가 남고, 감사 스냅숏에는 시각이 있을 때만 `plannedStartTime`을 넣는다(기존 기록 모양 유지). 지난주 복사가 시각도 복사한다. 주 표 칸에도 시각을 작게 보인다.
  - 가능 판정: 근무 시작 전은 비는 시간이 아니다. 출근 기록이 있으면 출근 시각, 없으면 근무 예정의 출근 예정 시각이 근무 시작이다(D28). 마지막 슬롯보다 뒤로 읽히는 시각(첫 슬롯 전 아침 출근, 예: 첫 슬롯 11:00에 09:00)은 영업 시작부터로 본다(리뷰 지적: 그대로 두면 다음 날 새벽으로 읽혀 하루 종일 불가가 된다). 현황 줄의 `출근 전 · HH:MM`은 티켓 04 그대로 이 값을 읽는다.
  - 가정: (1) 자리 수는 출근 기록이 있으면 출근 시각부터 퇴근 전까지, 없으면 근무 예정의 출근 예정 시각(비었으면 종일)부터 센다. (2) **D25 공식과 다른 점(확인 필요):** 일하지 않는 Therapist(출근 기록도 근무 예정도 없음)에게 배정된 콜은 남은 자리를 줄이지 않는다. 그 사람은 자리 수에도 없어서, 빼면 근무표를 안 채운 사람의 지명 예약이 다른 사람의 자리를 깎는다. 같은 규칙으로, 담은 지명 손님도 그 Therapist가 그때 일하면서 비어 있을 때만 자리를 쓴다(바쁜 사람·일하지 않는 사람을 경고 후 담으면 남은 자리를 쓰지 않는다). (3) `HH:MM 남은 자리 n / N`은 고른 시각의 값이고, 넘침 판정은 손님마다 코스 구간 전체로 본다. (4) 남은 자리가 음수면 그대로 보인다. (5) 출근 기록 시각 기준은 근무표가 없는 사람에게도 같다.
