# 04: 현장 화면 재구성: 객실, 실시간, TV

**What to build:** 객실, 실시간, TV 화면을 01의 화면 골격과 현장 시안을 기준으로 다시 구성한다. 동작과 데이터는 바꾸지 않는다. 표시 종료, 종료 확인 필요, 30초 갱신, 마지막 갱신 시각, 읽기 전용 TV가 그대로 유지된다. 겹친 콜 표시는 14에서 붙인다. (스펙 "객실·실시간·TV", 스토리 35–36)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 객실과 실시간에 마지막 갱신 시각과 갱신 지연이 항상 보인다.
- [ ] 카드의 상태, 표시 종료, 남은 시간은 객실 상태 서비스가 준 값을 그대로 그린다. 화면에서 점유나 양보를 계산하지 않는다.
- [ ] TV는 읽기 전용, 30초 갱신, 표시 종료와 종료 확인 필요만 보여 준다. 편집 기능과 고객 연락처는 없다.
- [ ] 웨이터와 조회 전용 사용자가 보는 정보 범위는 그대로다.
- [ ] 휴대폰 폭에서 실시간이 짧은 카드로 읽힌다. 데스크톱 화면을 축소해서 보여 주지 않는다.
- [ ] 두 언어, 글자와 색을 함께 쓰는 상태 표현, 동작 줄이기를 확인하고, 기존 객실·실시간·TV E2E가 통과한다.
