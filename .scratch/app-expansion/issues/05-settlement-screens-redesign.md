# 05: 정산 화면 재구성: Therapist, 귀케어, 운영팀

**What to build:** Therapist 출근과 일별 정산, 귀케어 출근과 일별 정산, 운영팀 출근과 일일·월 인센티브 화면을 01의 골격과 정산 시안을 기준으로 다시 구성한다. 계산식, 금액, 권한, 잠금, 기존 Therapist 지급완료 동작은 바꾸지 않는다. 지급 확인 열은 30과 31에서 붙인다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 세 직군의 계산 결과가 재구성 전과 같다. 기존 서비스 테스트와 E2E가 통과한다.
- [ ] 직원 비교 표와, 선택한 직원의 근거(출근, 해당 콜, 적용 정책)가 구분되어 보인다.
- [ ] 금액은 오른쪽 정렬과 표 숫자 형식이다. 계산 근거가 없으면 0 대신 근거 없음 상태가 보인다.
- [ ] 잠긴 운영월은 잠금 이유와 함께 읽기 전용으로 보인다.
- [ ] 직원 패널의 근거 콜에서 관리자는 원장의 그 날짜와 콜로 간다(콜 상세 패널이 열리는 것은 13). 정산 담당에게는 링크 대신 그 자리의 콜 요약(날짜, 예약시각, 코스, Therapist, 상태)이 보이고 원장 라우트나 콜 쓰기 권한이 생기지 않는다. (스토리 148)
- [ ] 두 언어, 키보드 이동, 44px 주요 조작 영역을 확인한다.
