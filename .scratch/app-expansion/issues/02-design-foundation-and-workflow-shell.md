# 02: 디자인 기반과 업무 흐름 탐색 셸

**What to build:** 01에서 정한 탐색 방식(`docs/design/2026-10-14-workflow-information-architecture.md`의 "업무 흐름 도크 + 화면 도구줄 + 작업면 위 패널")과 공통 컴포넌트를 앱에 넣는다. 모든 기존 화면이 새 셸 안에서 열리고, 좌측 사이드바와 상단바는 사라진다. 구역 이동은 PC를 포함한 모든 폭에서 화면 아래 업무 흐름 도크가 맡는다. Royal Gold 토큰을 정리해 색, 글꼴, 모서리, 간격, 움직임 규칙을 모든 화면이 함께 쓴다. 각 화면 본문의 재배치는 뒤의 티켓이 맡는다. (스펙 "탐색 셸", "언어, 디자인, 기기", 스토리 137–145, 149)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 모든 기존 라우트가 새 탐색 셸에서 열린다. 역할별로 보이는 메뉴와 서버 접근 범위는 지금과 같아서 넓어지지도 좁아지지도 않는다.
- [ ] 사이드바와 상단바가 없다. 현재 운영월, 서비스 날짜, 연결 상태처럼 01이 정한 맥락 정보가 각 화면 도구줄의 정해진 자리에 보인다.
- [ ] 업무 흐름 도크는 PC·태블릿·휴대폰 모두 화면 아래에 있고, 구역을 원장, 현장, 고객, 정산, 마감, 보고, 설정 순서로 보인다. 역할마다 들어갈 수 있는 구역만 보이고 순서는 바뀌지 않는다. 840px 미만 폭에서는 구역이 다섯 개 이상인 역할에게 네 구역과 "더보기"다. 840px 이상에서는 역할의 구역을 모두 보이고, 베트남어 라벨이 한 줄에 들어가는지 확인한다. 웨이터에게는 도크가 없다. 고객 구역은 고객 화면(03)이 생기기 전까지 보이지 않는다.
- [ ] 화면마다 라벨, 구역, 접근 역할을 적은 라우트 목록 하나에서 도크 항목과 서버의 접근 검사가 함께 나온다. 메뉴 규칙과 접근 규칙이 두 곳에 따로 있지 않다.
- [ ] "나" 메뉴에 표시 이름, 역할, 언어 전환, 로그아웃이 있다. 로그아웃하면 세션이 끝나고 로그인 화면으로 간다.
- [ ] 날짜가 있는 구역 사이를 도크로 옮기면 고른 운영월·날짜가 유지된다. 원장 구역은 도크로 들어가면 늘 원장 탭으로 열린다.
- [ ] 운영월이 없을 때 관리자는 운영월 설정 링크를, 다른 역할은 모든 화면에서 "관리자에게 운영월 생성을 요청하세요" 안내를 본다. 대시보드 빈 상태의 링크는 그 역할이 들어갈 수 있는 화면만 가리킨다.
- [ ] 화면 맨 앞에 "본문으로"와 "업무 이동으로" 건너뛰기 링크가 있고, 도크가 포커스된 요소를 가리지 않는다(WCAG 2.4.1, 2.4.11).
- [ ] html·body의 최소 너비 1280px를 없애고, 폭(600·840·1200px 경계)에 따라 셸이 바뀐다. 폭은 화면 모양만 바꾸고 권한은 바꾸지 않는다.
- [ ] 색은 Royal Gold 토큰으로 통일하고, 상태색과 오류색은 의미 토큰으로 따로 둔다. 실제 대비를 재서 기록한다.
- [ ] 상태와 경고는 글자와 색으로 함께 표현하고 이모지를 쓰지 않는다.
- [ ] 공통 컴포넌트가 생긴다: 상태 표시, 경고, 저장 상태, 패널·서랍, 탭, 확인 다이얼로그, 로딩·빈 상태·오류·잠금·갱신 지연 상태.
- [ ] 주요 조작 영역은 44px 이상이고, 금액·시각·건수는 표 숫자 형식이다.
- [ ] 움직임은 색과 투명도만 150–250ms 동안 바뀌고, 동작 줄이기 설정에서는 즉시 바뀐다.
- [ ] 다이얼로그와 패널은 포커스를 가두고, 닫으면 포커스를 원래 자리로 돌려준다.
- [ ] TV는 셸 없이 읽기 전용 전체 화면을 유지한다.
- [ ] 한국어·베트남어 전환과 기본 베트남어가 그대로 동작하고, 새 문구는 두 언어로 있다.
- [ ] 탐색·권한·언어에 관한 기존 E2E 스토리를 새 셸에 맞춰 고치고 통과시킨다.
