# 25: 고객 연결 정정

**What to build:** 콜 상세 패널에서 잘못 연결된 콜의 고객을 사유와 함께 바꾸거나 연결을 해제한다. 입력은 콜, 새 고객(또는 해제), 필수 사유, 마지막으로 받은 updatedAt이다. 감사 기록에 이전 고객, 새 고객, 사유, 처리자가 남는다. 콜의 고객/메모는 바꾸지 않는다. (스펙 F06, ADR 0003, 스토리 81–83, 91, V09)

**Blocked by:** 13, 15, 22

**Status:** ready-for-agent

- [ ] 마감확정이나 잠금 상태인 운영월의 콜은 거절되고, 관리자가 재오픈한 뒤에는 바꿀 수 있다.
- [ ] updatedAt이 오래되었으면 STALE_CALL로 거절되고 쓰기와 감사가 없다.
- [ ] 사유가 없으면 거절된다.
- [ ] 카운터와 관리자가 콜 쓰기 권한으로만 할 수 있고, 다른 역할이 서버 액션을 직접 호출하면 거절된다.
- [ ] 새 고객 후보는 22의 비교 정보로 고르며 자동 연결이 없다.
- [ ] 콜 상세 패널에서 고객 화면으로 바로 갈 수 있다.
- [ ] 콜 서비스 테스트로 감사 내용, 잠금 거절, STALE_CALL을 확인한다. 새 문구는 두 언어로 있다.
