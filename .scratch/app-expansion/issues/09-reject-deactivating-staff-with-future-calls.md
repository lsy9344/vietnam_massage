# 09: 앞으로 콜이 잡힌 직원의 비활성 거절

**What to build:** 관리자가 직원을 비활성으로 바꿀 때, 오늘 이후 날짜에 노쇼·취소가 아닌 콜(오늘의 방문완료 포함)에 그 직원이 어느 배정 역할(Therapist 1, Therapist 2, 귀케어)로든 들어 있으면 HAS_FUTURE_CALLS로 거절한다. 직원 화면에는 건수와 각 콜의 날짜·예약시각을 보여 준다. (스펙 B08, 스토리 107–109, V01 일부)

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 오늘 이후의 콜이 세 배정 역할 중 어느 것이어도 거절된다. 반환값에 건수와 각 콜의 날짜·예약시각이 담긴다.
- [x] 노쇼 콜만 남았거나 어제 이전의 콜만 있는 직원은 비활성으로 바뀐다.
- [x] 이미 비활성인 직원은 지금처럼 그 상태를 돌려준다.
- [x] 비활성으로 바꾼 뒤에도 과거 콜의 배정 이름이 원장에 남는다.
- [x] 오늘은 Asia/Ho_Chi_Minh 달력날이다. 직원 서비스 테스트는 시각을 입력으로 넘겨 오늘·어제 경계를 확인한다.
- [x] 거절 때 감사 기록이 생기지 않는다.
- [x] 직원 화면이 거절 사유와 콜 목록을 두 언어로 보여 준다.

- 목록은 날짜 순, 같은 날 안에서는 원장과 같은 시간 슬롯 순서다(01:00 슬롯이 그날의 끝에 온다). 스펙이 순서를 요구하지는 않지만 문자열 순서면 01:00 콜이 오후 콜보다 앞에 보여 헷갈린다.
- 노쇼·취소 상태 값은 콜 서비스의 비공개 술어와 같은 값을 직원 서비스에 따로 두었다. masters는 calls를 가져오지 않는 방향(`src/modules/README.md`)이라 calls에서 가져오지 않았다.
- 서버 액션은 거절 때 `{ ok: false, domainErrorCode: "HAS_FUTURE_CALLS", futureCalls }`만 돌려주고, 직원 패널의 비활성 전환 묶음이 사유(건수)·안내·콜 목록(목록 행 카드 안 날짜·시각 캡슐, design.md 6.9·6.10)을 ko/vi 메시지 키로 그린다. 비활성 안내 문장에 "오늘 이후 콜에 배정돼 있으면 비활성으로 바꿀 수 없다"를 더했다. `DateCapsule`은 05의 `src/components/ui/date-capsule.tsx`를 바이트 그대로 복사했다.
