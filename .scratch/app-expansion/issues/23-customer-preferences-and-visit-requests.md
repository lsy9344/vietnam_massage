# 23: 고객 공통 선호·주의사항과 방문별 요청

**What to build:** 고객에 "고객 공통 선호·주의사항" 칸을, 콜에 "방문별 요청" 칸을 새로 더한다. 고객 화면에서 공통 정보를 적고, 원장의 펼침 영역과 빠른 예약의 객실·메모 단계에서 방문별 요청을 적는다. 기존 고객 메모와 콜 비고는 지금 이름 그대로 두고 옮기거나 나누지 않는다. 고객/메모는 지금처럼 콜에 적힌 손님 표기다. (스펙 F06, ADR 0003, 스토리 74–75, 84–85, V09)

**Blocked by:** 19, 20

**Status:** ready-for-agent

- [ ] 두 칸이 따로 저장되고 각 화면에서 구분되어 보인다.
- [ ] 마이그레이션은 기존 메모와 비고를 옮기거나 추측으로 다시 분류하지 않는다.
- [ ] 고객 프로필(이름, 연락처, 공통 선호·주의사항)은 운영월 잠금과 상관없이 지금 권한대로 수정되고, 과거 콜의 고객/메모를 덮어쓰지 않는다.
- [ ] 방문별 요청은 콜 저장 규칙(운영월 잠금, 충돌 검사, 감사)을 따른다.
- [ ] 콜 서비스 테스트와 뷰 테스트로 두 칸의 저장과 표시를 확인한다. 새 라벨은 두 언어로 있다.
