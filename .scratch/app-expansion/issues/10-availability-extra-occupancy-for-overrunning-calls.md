# 10: 가능 코스: 끝나지 않은 시술의 추가 점유

**What to build:** 고른 서비스 날짜가 오늘이고 사용중인 콜이 표시 종료를 지났다면, [표시 종료, 지금) 구간을 그 Therapist의 추가 점유로 보아 가능 코스에서 불가로 보이게 한다. 사유는 "시술 중 · {표시 종료} 종료 확인", 비는 시각은 지금이다. 그런 Therapist의 가능 후보에는 "시간표상 가능 · 앞 시술 종료 확인 필요"를 붙인다. 가능 코스 판정은 지금 시각을 입력으로 받고, 입력이 없으면 서버 시각을 쓴다. (스펙 B01, F02 일부, ADR 0001, 스토리 1–4, 11, V01)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 오늘 14:00 시작, 60분, 다음 예약 없음, 사용중, 지금 15:20이면 15:00은 불가(15:00 종료 확인, 비는 시각 15:20)이고, 15:30은 가능이면서 "앞 시술 종료 확인 필요"가 붙는다.
- [ ] 같은 콜이 예약 상태이거나 고른 날짜가 어제면 추가 점유가 없다. 청소중·방문완료·노쇼·취소도 추가 점유가 없다. 지금이 표시 종료보다 이르거나 같으면 추가 점유가 없다.
- [ ] 기존 점유와 추가 점유 중 하나라도 고른 시각을 덮으면 불가이고, 비는 시각은 두 구간의 끝 중 늦은 시각이다.
- [ ] Therapist 1과 Therapist 2 배정을 모두 같은 사람의 점유로 센다.
- [ ] 추가 점유는 표시 종료, 뒤 콜의 예약시각, 코스, 금액을 바꾸지 않는다.
- [ ] 판정 결과는 안정적인 코드와 시각으로 반환하고, 문장은 화면이 두 언어 메시지 키로 만든다. 화면은 점유를 다시 계산하지 않는다.
- [ ] 콜 서비스 테스트가 위 예시와 경계를 반환값으로 확인하고, 뷰 테스트가 문장과 시각을 그리는지 확인한다.
