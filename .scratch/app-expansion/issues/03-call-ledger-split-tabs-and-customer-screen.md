# 03: 콜 원장 화면 분리: 원장 탭, 하루 수납·지출 탭, 고객 화면

**What to build:** 지금 한 페이지에 위에서 아래로 쌓인 기능을 스펙의 분리 기준대로 나눈다. 원장 탭에는 날짜, 상태별 건수, 원장 표만 두어 원장 표가 첫 화면 위쪽에 보인다. 결제수단별 합계, 현금 잔액, 계좌 잔액, 순매출, 코스 요약, 계산 경고 건수, 지출 입력과 목록은 같은 날짜의 "하루 수납·지출" 탭으로 옮긴다. 고객 검색, 전체 방문 이력, 고객 등록·정정은 관리자와 카운터만 여는 새 고객 화면으로 옮긴다. 화면 골격은 01·02의 결과와 콜 원장·고객 시안을 따른다. 빠른 예약은 20에서, 콜 상세 패널은 13에서, 보기 전환은 19에서 붙인다. 지금 원장 위에 펼쳐진 가능 코스 영역은 20에서 빠른 예약 패널로 옮길 때까지 원장 탭에 그대로 둔다. (스펙 F08, ADR 0002·0003, 스토리 86–90, 94, V14 일부)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 원장 탭에는 운영월·날짜, 상태별 건수 한 줄, 원장 표가 있고 원장 표가 첫 화면 위쪽에 보인다. 지출과 금액 요약은 원장 탭에 없다.
- [ ] "하루 수납·지출" 탭은 원장 탭과 운영월·날짜를 함께 쓴다. 결제수단별 합계, 현금 잔액, 계좌 잔액, 순매출, 코스 요약, 계산 경고 건수, 지출 입력과 목록이 지금 계산과 같은 값으로 나온다. 역할별 금액 노출 규칙은 그대로다.
- [ ] 선택한 탭이 주소에 남아 새로고침과 뒤로 가기에서 복원된다.
- [ ] 고객 화면은 관리자와 카운터만 열 수 있고, 다른 역할은 서버에서 거절된다.
- [ ] 고객 화면은 기존 콜 서비스 검색으로 후보를 찾는다. 고객을 고르면 공통 정보와 방문 이력이 보이고, 이력 행에서 그 날짜의 원장으로 이동한다.
- [ ] 고객 등록·정정은 고객 화면에서만 한다. 원장 탭에는 고객 화면으로 가는 링크만 둔다.
- [ ] 하루 수납·지출 탭의 계산 경고 건수를 펼치면 계산 오류가 있는 콜(예약시각, 고객/메모, 계산 상태)이 보이고, 각 항목은 원장의 그 날짜와 콜로 간다. 콜 상세 패널이 열리는 것은 13에서 붙는다. (스토리 147)
- [ ] 지출 저장과 고객 저장은 지금처럼 동작한다.
- [ ] 원장 페이지에서 고객 등록이나 지출 입력을 찾던 기존 E2E 스토리를 새 위치에 맞춰 고친다. 탭 전환, 주소 복원, 고객 화면 접근 권한을 확인하는 E2E를 더한다.
- [ ] 뷰 정적 렌더 테스트로 각 탭이 서비스가 준 값을 그대로 그리는지 확인한다.
- [ ] 새 문구는 두 언어로 있다.
