# 17: 저장 충돌 비교와 다시 반영

**What to build:** 행이 충돌 확인 필요가 되면 콜 상세 패널에 충돌 비교가 열린다. 원장 필드 순서대로 내 값과 최신 저장 값을 나란히 보여 주고, 필드마다 "내 값 쓰기"를 골라 최신 내용 위에 필요한 값만 다시 반영해 저장한다. 다시 저장할 때는 최신 updatedAt을 쓰므로 다시 버전 검사를 받는다. (스펙 B07, 스토리 39–40, 42–43, V05)

**Blocked by:** 13, 15

**Status:** ready-for-agent

- [ ] 비교 화면의 필드 순서가 원장과 같고, 내 값과 최신 값이 다른 필드가 구분되어 보인다.
- [ ] "내 값 쓰기"를 고른 필드만 최신 내용 위에 반영된다. 강제 덮어쓰기는 없다.
- [ ] 비교하는 동안 다른 화면이 또 수정했다면 다시 저장할 때 충돌로 알려 준다.
- [ ] "최신 내용으로 다시 불러오기"는 초안을 최신 행으로 바꾼다.
- [ ] 키보드만으로 비교와 반영을 할 수 있고, 패널은 포커스를 가두며 닫으면 원래 자리로 돌려준다. 새 문구는 두 언어로 있다.
- [ ] 두 브라우저 문맥 E2E로 충돌 → 비교 → 다시 반영 → 저장을 확인한다.
