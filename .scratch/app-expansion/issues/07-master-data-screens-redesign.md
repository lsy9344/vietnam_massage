# 07: 기준정보 화면 재구성

**What to build:** 운영월, 객실, 코드·시간 슬롯, 직원, 코스·정책·수당, 시트 매핑 화면을 01의 골격과 기준정보 시안을 기준으로 다시 구성한다. 입력 항목과 규칙은 바꾸지 않는다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 각 화면은 변경 영향과 비활성 상태를 먼저 보여 준다. 과거에 참조된 항목은 삭제 대신 비활성이라는 사실을 행에 설명한다.
- [ ] 시안에는 있지만 지금 데이터 계약에 없는 입력 항목이나 하위 메뉴를 추가하지 않는다.
- [ ] 관리자 전용 범위가 그대로이고 기존 기준정보 E2E가 통과한다.
- [ ] 두 언어, 키보드 이동, 44px 주요 조작 영역을 확인한다.
