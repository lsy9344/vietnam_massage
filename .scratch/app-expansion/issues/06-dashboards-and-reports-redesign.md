# 06: 대시보드와 리포트 재구성

**What to build:** 오늘 대시보드, 월간 대시보드, 리포트, 휴대폰의 오늘 현황을 01의 골격과 대시보드 시안을 기준으로 다시 구성한다. 집계는 서비스 값을 그대로 쓰고 화면에서 다시 계산하지 않는다. (ADR 0002)

**Blocked by:** 02

**Status:** done

- [x] 오늘 화면은 지금 필요한 상태, 경고, 진행 중인 콜을 먼저 보여 준다. 현금 잔액과 계좌 잔액은 오늘 화면에 두지 않는다. 그 값은 하루 수납·지출 탭에만 있다(명세 F08 기준 5).
- [x] 순매출, 현금 잔액, 계좌 잔액, 지급 합계를 한 값처럼 합치거나 같은 색으로 칠하지 않는다.
- [x] 계산 근거가 없는 데이터는 0으로 그린 차트 대신 빈 상태로 보인다.
- [x] 차트 색은 객실 상태색과 구분하고 표, 범례, 글자를 함께 둔다.
- [x] 휴대폰 폭에서는 권한 안의 오늘 현황이 짧은 카드로 보이고, 데스크톱 화면을 축소하지 않는다.
- [x] 역할별 접근 범위가 그대로이고 기존 대시보드 E2E가 통과한다. 두 언어를 확인한다.
