# 12: 출근 상태 구분, 근무 확인 필요, 퇴근 경고

**What to build:** 가능 코스 행에 그날의 Therapist 출근 기록에 따라 출근 전, 출근, 퇴근(현재 퇴근)을 구분해 보인다. 오늘 날짜에서 지금보다 30분을 넘겨 뒤의 시각을 볼 때 출근 상태가 아니면 "근무 확인 필요"를 붙인다. 출근 화면에서 사용중 콜이 있는 Therapist의 퇴근을 저장하면 저장은 되고 "시술 중인 콜이 있습니다"가 보인다. (스펙 B04, 스토리 8–10, 18, V01)

**Blocked by:** 10 (같은 가능 코스 판정과 테스트를 고친다)

**Status:** done

- [x] 출근 기록이 없으면 출근 전, 퇴근 시각이 없으면 출근, 퇴근 시각이 있으면 퇴근과 현재 퇴근이다.
- [x] 어떤 출근 상태에서도 행이 남고 코스 버튼이 꺼지지 않는다.
- [x] 40분 뒤 시각에는 근무 확인 필요가 붙고, 20분 뒤와 정확히 30분 뒤에는 붙지 않는다. 오늘이 아닌 날짜에는 붙지 않는다.
- [x] 귀케어와 운영팀은 가능 코스에 나오지 않는다.
- [x] 퇴근 저장 결과에 경고가 붙고, 콜은 취소되거나 바뀌지 않는다. Therapist 출근 서비스 테스트로 확인한다.
- [x] 새 문구는 두 언어로 있다.

## Comments

- 2026-10-15 구현 완료(`feat/ticket-12-attendance-state`, 기준 티켓 11 cb67d17). 가능 코스 행의 `attendance`는 `before_check_in` / `checked_in` / `checked_out`이고, 새 `shiftCheck`가 근무 확인 필요 여부다. "오늘"은 티켓 10 결정대로 지금이 들어 있는 영업일이고, 고른 시각 − 지금 > 30분일 때만 붙는다. 출근 상태는 판정과 코스 판정을 바꾸지 않는다.
- 퇴근 경고: `TherapistAttendanceDto.warnings`에 `{ code: "IN_SERVICE_CALL", serviceCallIds }`를 담는다. 그날 Therapist 1·2로 배정된(활성 배정) 사용중 콜이 있고 퇴근 시각이 저장돼 있을 때만이다. 콜은 바꾸지 않는다. 사용중 상태 값은 콜 서비스의 `IN_USE_SERVICE_CALL_STATUSES`를 함께 쓴다.
- 경고를 저장 결과뿐 아니라 날짜별 출근 목록에도 싣는다. 직원 패널의 출퇴근 폼은 저장 뒤 다시 읽은 출퇴근 시각을 key로 다시 마운트되므로, 저장 결과에만 두면 경고가 곧바로 사라진다. key에서 시각을 빼면 첫 저장(id 생성)과 비우기 뒤의 입력칸 초기화가 깨져서 이쪽을 택했다. 그 결과 사용중 콜이 남아 있는 동안에는 패널을 다시 열어도 경고가 보인다.
- 가정: "퇴근(현재 퇴근)"은 한 문구로 그린다(ko "퇴근(현재 퇴근)", vi "Đã về (hiện đã về)"). 기록 상태와 현재 상태를 따로 보여야 한다면 문구만 바꾸면 된다.
