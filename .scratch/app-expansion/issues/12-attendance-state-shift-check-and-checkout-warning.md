# 12: 출근 상태 구분, 근무 확인 필요, 퇴근 경고

**What to build:** 가능 코스 행에 그날의 Therapist 출근 기록에 따라 출근 전, 출근, 퇴근(현재 퇴근)을 구분해 보인다. 오늘 날짜에서 지금보다 30분을 넘겨 뒤의 시각을 볼 때 출근 상태가 아니면 "근무 확인 필요"를 붙인다. 출근 화면에서 사용중 콜이 있는 Therapist의 퇴근을 저장하면 저장은 되고 "시술 중인 콜이 있습니다"가 보인다. (스펙 B04, 스토리 8–10, 18, V01)

**Blocked by:** 10 (같은 가능 코스 판정과 테스트를 고친다)

**Status:** ready-for-agent

- [ ] 출근 기록이 없으면 출근 전, 퇴근 시각이 없으면 출근, 퇴근 시각이 있으면 퇴근과 현재 퇴근이다.
- [ ] 어떤 출근 상태에서도 행이 남고 코스 버튼이 꺼지지 않는다.
- [ ] 40분 뒤 시각에는 근무 확인 필요가 붙고, 20분 뒤와 정확히 30분 뒤에는 붙지 않는다. 오늘이 아닌 날짜에는 붙지 않는다.
- [ ] 귀케어와 운영팀은 가능 코스에 나오지 않는다.
- [ ] 퇴근 저장 결과에 경고가 붙고, 콜은 취소되거나 바뀌지 않는다. Therapist 출근 서비스 테스트로 확인한다.
- [ ] 새 문구는 두 언어로 있다.
