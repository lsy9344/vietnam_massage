# 08: 감사와 로그인 화면 재구성

**What to build:** 감사 화면과 로그인 화면을 01의 골격과 해당 시안을 기준으로 다시 구성한다. 동작과 권한은 바꾸지 않는다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 감사 화면은 처리자, 시각, 대상, 변경 전·후, 사유를 먼저 보여 주고 원본 화면으로 이동할 수 있다.
- [ ] 감사 내용을 통해 고객 연락처나 수당, 편집 권한이 새로 드러나지 않는다.
- [ ] 로그인은 계정 인증만으로 권한을 정한다. 역할을 고르는 UI가 없다.
- [ ] 로그인 오류는 해당 필드에 연결되고 언어 전환이 된다.
- [ ] 기존 감사·로그인·권한 E2E가 통과한다. 두 언어를 확인한다.
