# 19: 원장 보기 전환

**What to build:** 원장 표를 예약·현장, 수납·정산, 전체 보기로 바꾼다. 같은 데이터를 다른 열 묶음으로 보여 주며, 예약시각·고객/메모·상태 열은 모든 보기에서 왼쪽에 고정된다. 드물게 쓰는 입력(확인 코드, 비고)과 경고 상세는 펼쳐서 본다. 선택한 보기는 주소에 남는다. (스펙 F02 "원장 보기", 스토리 89, 95–97, V14 일부)

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 예약·현장 보기는 예약시각, 실제입장, 객실, 고객/메모, 코스, Therapist 1·2, 귀케어, 상태, 경고를 보여 준다.
- [ ] 수납·정산 보기는 예약시각, 고객/메모, 상태, 할인, 결제수단, 결제금액, 확인 코드, 비고를 보여 주고, 권한이 있으면 수당 열도 보여 준다. 전체 보기는 모든 열을 보여 준다.
- [ ] 보기를 바꿔도 역할, 저장 규칙, 데이터, 저장하지 않은 초안이 그대로다. 수당, 귀케어 풀, 운영 콜 크레딧은 지금처럼 관리자에게만 보인다.
- [ ] 키보드 이동 순서가 보이는 열의 순서를 따른다.
- [ ] 보기가 주소에서 복원된다.
- [ ] 행 높이는 PC의 빠른 훑기와 태블릿의 조작성을 각각 확인해 정한다.
- [ ] 뷰 테스트로 보기별 열 구성을, E2E로 보기 전환 중의 초안 유지를 확인한다. 새 문구는 두 언어로 있다.
