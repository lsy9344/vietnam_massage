# 26: 휴대폰 원장 카드 목록

**What to build:** 휴대폰 폭에서 원장 탭은 넓은 표 대신 그날의 콜을 짧은 카드 목록(예약시각, 객실, 코스, Therapist, 상태, 첫 경고)으로 보여 준다. 카드를 누르면 콜 상세 패널이 읽기 형태로 열린다. (스펙 F08, 스토리 98, V14 일부)

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] 넓은 표를 축소해서 보여 주지 않는다. 빠른 예약과 표 편집은 태블릿 폭 이상에서만 보인다.
- [ ] 카드의 첫 경고는 서비스가 준 우선순위의 첫 항목이다.
- [ ] 권한 밖의 고객 연락처나 금액이 새로 보이지 않는다.
- [ ] 휴대폰 폭 E2E와 뷰 테스트로 확인한다. 새 문구는 두 언어로 있다.
