# 20: 빠른 예약 패널 기본 흐름

**What to build:** 원장 탭 머리의 주요 버튼으로 빠른 예약 패널을 연다. 패널은 고객(검색해 고르기, 또는 고객 없이 고객/메모만) → 날짜·예약시각("지금" 포함) → Therapist·코스(가능 코스 목록) → 객실·메모 → 저장의 한 방향으로 진행하고, 명시적인 저장 버튼으로만 예약 상태의 콜을 만든다. 원장 위에 늘 펼쳐 두던 가능 코스 영역은 없애고 패널 안으로 옮긴다. 가능 버튼은 패널의 Therapist와 코스만 채운다. 저장하면 그 콜이 원장 표에 바로 나타나고 포커스가 그 행으로 간다. 패널 저장은 16의 요청 id 계약을 쓴다. 두 명 코스와 경고 확인 후 배정은 21에서, 새 고객과 최근 방문 가져오기는 24에서 더한다. (스펙 F01, B05, 스토리 14–17, 53–56, 58–59, 63–67, 69–70, 92, V03)

**Blocked by:** 03, 16

**Status:** ready-for-agent

- [ ] "지금"은 오늘 날짜와, 지금을 넘지 않는 마지막 활성 슬롯을 고르고 가능 목록을 펼친다. 지금이 첫 슬롯보다 이르면 첫 슬롯을 고른다. 저장하거나 Therapist를 고르지 않는다. 슬롯 선택은 순수 함수 테스트로 확인한다.
- [ ] 가능 버튼과 "지금"만으로는 콜이 생기지 않는다.
- [ ] 빠른 예약 저장은 콜 서비스의 작업 하나이고, 원장 저장과 같은 필수 입력, 활성 여부, 운영월 잠금, 권한 검사를 받는다. 상태는 예약이다.
- [ ] 객실을 비워 둔 예약이 저장된다. 사용중, 청소중, 방문완료에 객실이 필요한 기존 규칙은 그대로다.
- [ ] 단계를 오가도 고른 값이 남고, 검증 오류는 해당 필드 옆과 패널 요약에 함께 나온다.
- [ ] 저장 중, 완료, 실패가 보인다. 같은 요청 id로 다시 보내면 이미 만든 콜이 돌아온다.
- [ ] 저장하지 않은 값이 있는 채로 패널을 닫으면 안내하고, 취소하면 값이 남는다.
- [ ] 키보드만으로 끝까지 쓸 수 있고, 패널을 닫으면 포커스가 패널을 연 버튼으로 돌아온다. 태블릿에서는 단계마다 한 화면을 쓴다. 휴대폰 폭에서는 빠른 예약을 제공하지 않는다.
- [ ] 패널의 열림 상태와 초안은 주소에 남지 않는다.
- [ ] 원장 표에 새 행을 직접 적는 기존 방법은 그대로이고, 가능 버튼이 없는 코스도 원장에 적어 저장할 수 있다.
- [ ] PC와 태블릿 폭의 빠른 예약 E2E를 확인한다. 새 문구는 두 언어로 있다.
