# 13: 원장 행 경고 목록과 콜 상세 패널

**What to build:** 콜 행이 경고를 우선순위 목록(앞 시술 미완료 → 객실 겹침 → 양보 → 계산 오류)으로 돌려주고, 원장 행에는 첫 경고와 "+N"을 보여 준다. "앞 시술이 아직 끝나지 않았습니다" 경고를 새로 판정한다. 행이나 경고를 누르면 원장 위에 콜 상세 패널이 열리고, 주소에 콜 id가 남아 그 주소로 바로 열 수도 있다. 패널은 그 콜의 모든 경고와 관련 콜을 보여 주고, 관련 콜로 이동하게 한다. 저장 상태 표시는 경고와 다른 자리에 둔다. 객실 겹침 경고는 14에서 더한다. (스펙 B02, ADR 0001, 스토리 19–22, 27–30, 93, V01)

**Blocked by:** 03

**Status:** done

- [x] 같은 날 같은 Therapist(두 배정 역할 모두)의 다른 콜이 사용중이고, 그 콜의 표시 종료가 이 콜의 예약시각보다 같거나 이르며, 지금이 그 표시 종료보다 늦으면 이 콜에 앞 시술 미완료가 붙는다. 이 콜이 노쇼나 취소면 붙지 않는다.
- [x] 15:00 사용중 콜의 표시 종료가 16:00 예약에 양보해 16:00이 되었고 지금이 16:00을 넘었다면, 뒤 콜의 예약시각은 16:00 그대로이고 앞 시술 미완료가 붙는다. 앞 콜에는 "4:00 예약이 있습니다"가 그대로 남는다.
- [x] 경고는 코드, 관련 시각, 관련 콜 id로 반환하고, 날짜별 콜 목록은 지금 시각을 입력으로 받는다.
- [x] 원장 행에는 첫 경고와 나머지 건수만 보인다. 경고가 있어도 저장은 된다.
- [x] 주소의 콜 id로 패널이 열린다. 패널을 열고 닫아도 원장의 날짜와 초안은 그대로이고, 닫으면 포커스가 원래 행으로 돌아온다.
- [x] 패널의 관련 콜을 누르면 같은 원장의 그 콜로 이동한다. 패널은 원장에 접근할 수 있는 역할에게만 열린다.
- [x] 콜 서비스 테스트로 경고 코드와 순서를, 뷰 테스트로 첫 경고와 "+N"을 확인한다. 새 문구는 두 언어로 있다.

## Comments

- 2026-10-15 구현 완료(브랜치 `feat/ticket-13-row-warnings-detail-panel`, main 260a0c1 위). 09–12는 아직 main에 없는 프리뷰 줄이라 이 브랜치는 main에서 따로 땄다. 프리뷰 줄에 올릴 때 `listServiceCallsForDate`·`toRowDto`·ko/vi 메시지에서 충돌할 수 있다.
- 서비스: 행 DTO에 `warnings: { code, relatedTime, relatedCallIds }[]`가 생겼다. 순서는 `CALL_ROW_WARNING_ORDER`(앞 시술 미완료 → 객실 겹침 → 양보 → 계산 오류)이고, `room_overlap`은 코드와 순서 자리만 있고 판정은 14가 더한다. `listServiceCallsForDate({ now })`가 지금 시각을 받는다(없으면 서버 시각). 기존 `warningTime`은 그대로 두었다(실제입장 칸의 문장).
- 앞 시술 미완료는 "사용중"인 콜만 앞 콜로 센다(청소중·방문완료는 아니다). 날짜가 지난 원장에서도 사용중으로 남은 콜이 있으면 붙는다(스펙 문장 그대로 — 지금이 표시 종료보다 늦으면). 관련 시각은 앞 콜들의 표시 종료 중 가장 늦은 것이다.
- 주소: 열린 콜 상세는 `?call=<콜 id>`다(`CALL_PARAM`). `ledgerCallHref`가 03의 `#call-…`에서 이 형식으로 바뀌었고, 행 id `call-<id>`는 그대로라 E2E 로케이터는 유지된다. 선택된 행은 `data-selected`로 03의 `:target` 모양을 이어받는다.
- 화면: 원장 표에 "경고" 칸이 새로 생겼고(저장상태 칸 앞) 첫 경고와 "+N"만 보인다. 경고가 없는 행에도 같은 자리에 "콜 상세 열기" 버튼이 있다. 입력칸·버튼이 아닌 행의 빈 자리를 눌러도 패널이 열린다. 패널은 비모달 `SidePanel`이고 1200px 이상에서는 표 옆, 미만에서는 표 위에 쌓인다. 표는 패널이 열려도 같은 자리라 날짜와 초안이 남는다.
- 접근: `/calls` 라우트가 관리자·카운터만 연다(`routes.ts`). 다른 역할은 주소의 call 매개변수가 있어도 첫 화면으로 돌아간다(E2E로 확인).
- 남긴 것: 패널의 "고객 화면 · 고객 연결 정정"은 22·25 몫이라 넣지 않았다. 다른 행을 저장해 바뀐 경고는 서버가 다시 준 행(revalidatePath)으로 갱신된다.
