# 03. 빠른 예약·고객 응대·연결 정정

Status: needs-triage

Depends on: 01, 02

## 범위

통합 명세 F01·F06, V03·V09. 기존 원장 내 빠른 예약 패널, 고객 공통 선호·주의사항과 방문별 요청, 최근 방문의 선택적 가져오기, 후보 비교·연결 정정을 구현한다.

## 완료 기준

- 고객 → 날짜·시각 → Therapist·코스 → 객실·메모 → 명시적 저장 흐름에서 입력이 유지된다.
- 두 명 코스는 서로 다른 두 명을 선택한다. 필수 누락과 경고 후 수동 배정을 구분한다.
- 예약의 객실 선택은 선택 사항이며 사용중·청소중·방문완료의 기존 객실 필수 규칙만 유지한다.
- 후보 선택만으로 저장하지 않으며 경고·수동 입력 경로가 잘못된 가능 보장으로 보이지 않는다.
- 최근 방문은 선택한 값만 가져오고 비활성 직원·코스의 현재 유효성을 우회하지 않는다.
- 같은 번호 후보가 자동 연결되지 않으며 연결 정정에 이전/이후 고객·행위자·사유가 남는다.
- 고객 프로필과 콜 연결의 마감 잠금 경계가 유지된다.

## 구현 전 확인

기존 고객/콜 메모 데이터를 추측으로 재분류하지 않는다. 패널 저장은 02의 복구 계약을 사용한다. 잠긴 월 재오픈 경로의 확장은 07에서 연동한다. 근무표 표시는 05 완료 후 추가 연동한다.
