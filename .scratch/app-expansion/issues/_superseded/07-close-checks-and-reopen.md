# 07. 마감 점검·예외 사유·확정 상태 재오픈

Status: needs-triage

Depends on: 01, 06

운영 조건: Q25 승인 완료. 마감 대상 월의 예약·사용중·청소중은 목록 확인과 사유 기록 후 예외 마감할 수 있다.

## 범위

통합 명세 F07·V10–V11. 기존 수납·지출·잔액 확인 동선, 확정 차단/예외 점검, 마감확정·잠금에서 관리자 재오픈을 구현한다.

## 완료 기준

- 계산 오류·지급 재확인 미처리는 서비스에서 확정을 거절한다.
- 미완료 콜 예외에는 확인 대상·사유·행위자가 남고 해당 마감 버전과 연결된다.
- 예약·사용중·청소중은 확인·사유 없이 예외 마감할 수 없고, 방문완료·취소·노쇼는 미완료 예외 목록에서 제외한다. 예외 사유로 계산 오류·지급 재확인 미처리를 우회하지 못한다.
- 정상 예약·취소·노쇼를 일괄 오류로 처리하거나 미완료를 자동 완료하지 않는다.
- 점검 후 데이터가 바뀌면 확정 시 다시 검사한다.
- 마감확정·잠금 모두 관리자만 사유를 남겨 검토중으로 되돌린다.
- 재확정은 새 버전, 과거 스냅샷·명세서 보존, 기존 시재·순매출 계산 불변을 확인한다.
- 점검 원본 이동이 정산 담당에게 콜 수정 권한을 부여하지 않는다.

## 구현 전 확인

기존 월마감 트랜잭션·스냅샷과 점검 증거 저장의 경계를 설계한다. 직접 원본에 접근할 수 없는 역할의 안내를 마련한다. 확정된 과거 스냅샷은 소급 재계산하지 않는다.
