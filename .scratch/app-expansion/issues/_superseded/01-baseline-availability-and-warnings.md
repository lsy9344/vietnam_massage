# 01. 가능 코스·현장 경고·직원 비활성 기본 보완

Status: needs-triage

Depends on: 없음

## 범위

통합 명세 B01–B06, B08–B09와 V01–V02의 서비스 판정·반환값을 구현한다. 미완료 추가 점유, 앞 시술 경고, 수당별 가능 코스, 출근 구분, 지금 슬롯, 객실 겹침, 미래 콜이 있는 직원 비활성 거절, 고객 이력 집계·동일 연락처 경고를 포함한다.

## 완료 기준

- 원본 보완안의 구체적인 시각 예시와 오늘/과거·맞닿음·30분 경계가 서비스 테스트로 확인된다.
- Therapist 두 배정 역할과 다른 한 명의 가능 조건을 확인한다.
- 수당 0과 수당 없음이 구분되고 정책 유효월은 기존 계산기와 일치한다.
- 화면은 점유·양보를 별도로 계산하지 않는다.
- 기존 표시 종료·금액·시재 계산과 과거 배정 이름이 유지된다.

## 구현 전 확인

기존 작업 트리의 콜·객실 변경을 먼저 확인한다. 가능한 코드·시각·관련 콜 DTO를 정하고 두 언어 표시에서 사용할 수 있게 한다. 화면 전체 개편은 04에서 수행한다.
