# 06. 세 직군 지급 확인·재확인·월 명세서

Status: needs-triage

Depends on: 없음

## 범위

통합 명세 F05·V08·V11, ADR 0004. 직군별 계산식은 유지하고 지급 확인·정정 사유·변경 이력·확인 당시 금액·재확인 표시·명세서와 인쇄를 구현한다.

## 완료 기준

- Therapist·귀케어·운영팀의 기존 계산 결과가 회귀 테스트에서 유지된다.
- 지급 확인 당시 금액과 기록이 원본 정정 후에도 보존되며 현재 금액과 차이를 확인할 수 있다.
- 금액 변경 시 재확인 필요, 사유를 동반한 재확인, 행위자와 변경 이력이 제공된다.
- 재확인 후 새 기준 금액·표시 해제·이전 이력 보존을 확인하고, 이후 재변경 시 다시 재확인 필요로 표시한다.
- 마감 전 명세서는 미확정, 마감 후에는 해당 버전의 금액을 사용한다.
- 화면·인쇄·PDF 저장에서 직원·운영월·버전과 근거가 보인다.

## 구현 전 확인

기존 지급완료 boolean의 데이터 이전과 과거 명세서 근거를 조사한다. 과거 확인 금액을 현재 계산값으로 꾸며 채우지 않는다. 마감 서비스에서 읽을 재확인 상태와 버전별 명세서 계약을 정하고 07과 연동한다. 실제 송금·분할 지급 전표는 제외한다.
