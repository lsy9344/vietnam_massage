# 02. 콜 저장 충돌·중복 방지·초안 복구

Status: needs-triage

Depends on: 없음

## 범위

통합 명세 B07·F03과 V05–V06. updatedAt 기반 충돌 거절, 초안별 신규 요청 id, 비교·재반영, 저장 결과와 응답 유실 안내를 구현한다.

## 완료 기준

- 동시 수정은 한 번만 반영되며 다른 초안은 보존된다. 버전 검사와 쓰기가 원자적으로 이루어진다.
- 동일 생성 요청의 동시 실행과 응답 유실 후 재시도에서도 콜 하나와 최초 생성 감사 기록만 생긴다.
- 충돌 비교 후 재저장도 다시 버전을 확인하며 강제 덮어쓰기가 없다.
- 연속 자동 저장은 자기 요청 때문에 거짓 충돌하거나 오래된 응답으로 입력을 되돌리지 않는다.
- 저장 중·완료·실패·확인 중과 미저장 이탈 안내가 구분된다.

## 구현 전 확인

요청 id 스키마 변경·유일성 범위·기존 데이터 null 처리·자동 저장 순서를 설계한다. 신규 고객을 포함하는 생성 경로에서 재시도 중복과 부분 성공을 점검한다. 지출·고객 저장 전체의 충돌 정책 변경과 브라우저 종료 후 복구는 제외한다.
