# 05. 날짜별 근무표와 예약 후보 연동

Status: needs-triage

Depends on: 01

## 범위

통합 명세 F04·V07. 근무 예정·휴무·미입력, 지난주 빈칸 복사, 예약이 있는 날의 휴무 변경 경고를 구현한다.

## 완료 기준

- 미입력을 휴무로 취급하지 않고 이미 입력된 근무 예정·휴무는 복사로 덮어쓰지 않는다.
- 휴무 변경 시 관련 예약을 안내하지만 예약시각·배정·상태는 자동으로 바꾸지 않는다.
- 카운터 후보 화면에서 당일 근무 예정과 실제 출근 상태를 구분한다.
- 근무표가 출퇴근 기록·만근·수당을 생성하거나 예약 저장을 막지 않는다.
- 편집은 관리자·정산 담당만 가능하다.

## 구현 전 확인

기존 정산 영역 내 배치와 날짜·직원 키를 정한다. 월 경계를 넘는 지난주 읽기와 대상 날짜의 쓰기 정책을 점검한다. 계획 데이터가 확정된 실제 출퇴근·수당을 수정하지 않게 한다. 시간별 교대·분할 근무는 제외한다.
