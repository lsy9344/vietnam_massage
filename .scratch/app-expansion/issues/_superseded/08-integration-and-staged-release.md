# 08. 전체 흐름 검증과 단계별 적용 확인

Status: needs-triage

Depends on: 01, 02, 03, 04, 05, 06, 07

## 범위

통합 명세 V01–V14의 누락을 확인하고 다섯 업무 영역의 실제 연결을 검증한다. 각 기능 단계의 검증을 이 작업까지 미루지 않는다. 이 작업은 이미 통과한 검사를 이유 없이 반복하는 대신 교차 기능의 남은 위험을 검증한다.

## 완료 기준

- 전화 고객 검색 → 빠른 예약 → 입장·객실 확인 → 완료·정산 → 지급 확인 → 마감·명세서 흐름을 확인한다.
- 근무표 변경·겹친 콜·동시 저장·응답 유실·지급 후 정정·재오픈을 관련 기능 간에 검증한다.
- 다섯 역할의 직접 서버 호출, 잠금 상태, 한국어·베트남어 오류·인쇄를 확인한다.
- PC·태블릿·휴대폰의 합의한 동선과 접근성을 확인한다.
- 데이터 이전의 적용 전후 결과, 과거 스냅샷 보존, 남는 제한을 기록한다.
- 단계별 적용 내용과 검증 결과가 실제 실행 결과와 일치한다.

## 적용 순서

01·02 기본 판정과 저장 → 03·04 전화·현장 → 05 근무표 및 후보 연동 → 06·07 지급·마감 → 전체 교차 검증. 독립적인 기술 조사와 구현은 의존 관계를 지키며 병행할 수 있다. 일정은 미정이며 배포 완료를 문서 작성 완료와 혼동하지 않는다.
