# Therapist 수당 일별 조회와 소중한날 휴가

사용자 확정: 2026-10-20.

- 기존 화면 구성과 탭을 유지한다. Therapist는 현재 영업일의 본인 코스 수당만 조회한다.
- 월 선택, 월 합계·월 보너스·월별 내역, 지난 날짜 수당을 노출하지 않는다. URL의 월·날짜 값으로도 과거 수당을 조회할 수 없다.
- 영업일은 베트남 현지 시각 03:00에 바뀐다. 00:00–02:59는 전날 영업일이다. 오늘 화면, 수당, 출퇴근, 근태 판정에 같은 기준을 쓴다.
- 화면이 계속 보이는 경우 03:00에 한 번 갱신한다. 기존 새로고침·화면 복귀 갱신도 유지한다.
- 과거 정산·지급 확인·감사 기록과 운영팀의 월 정산 기능은 보존한다.
- 기존 휴무 신청에 `소중한날 휴가`를 더한다. 오늘·미래 날짜에 신청할 수 있고 관리자·정산 담당의 승인을 거친다.
- 승인된 날짜는 본인 근태 달력에서 붉은 테두리·기호와 글자 범례로 표시한다. 승인함과 관리자 오늘 현황에도 같은 이름을 쓴다.
- 휴가 신청과 구분 저장은 기존 휴무 승인 흐름을 재사용한다. 금액·만근 판정은 기존 출퇴근 기록과 정산 규칙을 유지한다. 월 1회 자동 등록이나 신청 횟수 제한은 추가하지 않는다.

이번 결정은 `.scratch/therapist-accounts/spec.md` D19–D21·M8–M10과 ADR 0010의 Therapist 월 수당 열람 범위를 대체한다. 운영팀의 월 명세서는 변경하지 않는다.

## 완료 기준

- 다른 월·날짜를 URL에 붙여도 현재 영업일의 본인 수당만 보인다.
- 02:59와 03:00, 월·연도 경계에서 날짜가 올바르게 전환된다.
- 일반 휴무와 소중한날 휴가를 구분하여 신청·취소·승인할 수 있다.
- 승인된 휴가만 달력·관리자 현황에 표시되며 다른 신청이 뒤에 생겨도 휴가 표시가 유지된다.
- 한국어·베트남어와 휴대폰 폭에서 기존 화면 모양을 유지한다.

## DB 적용

`20261020121300_add_special_day_off_request`는 신청 종류 CHECK 제약의 허용값만 확장하며 기존 데이터는 바꾸지 않는다. 운영 DB 적용은 기존 D29에 따라 사용자 확인 후 실행한다.
