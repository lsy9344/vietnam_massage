# 04: 원장의 일행 묶음과 일행 동작

**What to build:** 원장 목록에서 일행을 붙여 보이고 일행 전체 입장, 일행 전체 취소, 일행에 1명 추가를 더한다. (스펙 D14)

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 같은 `partyId`의 콜은 머리 줄("고객/메모 일행 N명") 아래에 `partyPosition` 순으로 붙어 보인다. 일행 콜이 다른 흐름 묶음에 흩어지면(예: 1명만 완료) 각 묶음 안에서 붙고 "일행 2/3" 표시가 남는다.
- [ ] 일행 전체 입장: 예약 상태인 일행 콜을 지금 시각으로 입장 처리한다. 객실이 빈 손님만 객실을 고르게 한다. 한 건이라도 실패하면 어느 손님이 왜 실패했는지 보인다.
- [ ] 일행 전체 취소: 확인 창을 거친 뒤 남은 예약 콜을 취소한다.
- [ ] 일행에 1명 추가: 같은 시간·고객/메모·`partyId`로 빠른 예약을 미리 채워 연다. 저장하면 다음 `partyPosition`을 받는다.
- [ ] 시간·코스·매니저·결제·노쇼는 사람별로 고친다.
- [ ] 서비스 테스트와 E2E(3인 일행 전체 입장 → 결제 1명 → 1명 노쇼). 새 문구는 ko·vi.
