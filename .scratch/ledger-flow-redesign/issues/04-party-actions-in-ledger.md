# 04: 원장의 일행 묶음과 일행 동작

**What to build:** 원장 목록에서 일행을 붙여 보이고 일행 전체 입장, 일행 전체 취소, 일행에 1명 추가를 더한다. (스펙 D14)

**Blocked by:** 03

**Status:** ready-for-agent

- [x] 같은 `partyId`의 콜은 머리 줄("고객/메모 일행 N명") 아래에 `partyPosition` 순으로 붙어 보인다. 일행 콜이 다른 흐름 묶음에 흩어지면(예: 1명만 완료) 각 묶음 안에서 붙고 "일행 2/3" 표시가 남는다.
- [x] 일행 전체 입장: 예약 상태인 일행 콜을 지금 시각으로 입장 처리한다. 객실이 빈 손님만 객실을 고르게 한다. 한 건이라도 실패하면 어느 손님이 왜 실패했는지 보인다.
- [x] 일행 전체 취소: 확인 창을 거친 뒤 남은 예약 콜을 취소한다.
- [x] 일행에 1명 추가: 같은 시간·고객/메모·`partyId`로 빠른 예약을 미리 채워 연다. 저장하면 다음 `partyPosition`을 받는다.
- [x] 시간·코스·매니저·결제·노쇼는 사람별로 고친다.
- [x] 서비스 테스트와 E2E(3인 일행 전체 입장 → 결제 1명 → 1명 노쇼). 새 문구는 ko·vi.

## Comments

- 2026-10-16 구현(브랜치 feat/ledger-flow-redesign).
  - 행 DTO에 `partyId`·`partyPosition`을 넣었다(일행이 아니면 둘 다 null). 화면 테스트 픽스처 9개에 두 칸을 더했다.
  - 묶음: `ledgerFlowItems`(ledger-flow.ts)가 흐름 묶음 하나 안에서 일행을 처음 나오는 일행 콜 자리에 순번 순으로 모은다. 인원과 대표(가장 앞 순번)는 하루 전체로 본다. 흩어진 일행은 묶음마다 머리 줄이 있다. 전체 입장·취소 버튼은 예약 손님이 있는 머리 줄에, "1명 추가"는 일행의 첫 머리 줄에 한 번만 둔다.
  - 일행 전체 입장·취소는 서버 일괄 작업이 아니라, 머리 줄이 손님 줄들에 할 일을 알리고 각 줄이 자기 저장 상태(`callRowSaveReducer`)로 저장한다. 그래서 낡은 저장 거절·충돌 비교·떠나기 안내가 사람별 저장과 같다. 일부만 성공할 수 있고(전부 또는 전무가 아니다), 실패·충돌한 손님은 그 동작을 누른 예약 묶음 머리 줄에 "손님 N: 이유"로 보인다(예약이 남지 않았으면 첫 머리 줄). 그 뒤 사람별로 고친 저장의 실패는 머리 줄에 붙지 않는다.
  - 줄은 할 일을 받을 때 자기 초안이 아직 예약일 때만 한다(그 사이 입장한 손님을 취소하지 않는다). 입장 객실 고르기는 서버 행 기준으로 객실 없는 손님만 묻고, 빈 객실 중 일행의 다른 손님이 이미 쓰거나 고른 객실은 뺀다. 패널에서 객실을 막 지운 손님처럼 줄 초안에만 객실이 없으면 그 줄의 개별 객실 고르기가 열린다.
  - 전체 취소 상태 코드는 기준정보의 CANCELED(옛 값 "취소")다. 확인 창에 남은 예약 건수를 보인다.
  - 1명 추가: 원장 → 빠른 예약은 React 트리가 달라 창 이벤트(`quick-booking-party-join.ts`)로 잇는다. 패널은 새 요청 id로 처음부터, 시각·고객/메모·`partyId`를 채워 Therapist 단계에서 연다. 인원 선택과 고객 고르기는 숨긴다. 쓰던 초안이 있으면 버릴지 먼저 묻는다(티켓에 없던 확인 창, 초안을 말없이 지우지 않으려고).
  - 서비스: `createQuickBookingServiceCall`(→`createServiceCallRow`)이 `partyId`를 받으면 같은 운영월·같은 날의 그 일행 마지막 순번 + 1로 붙인다. 일행이 없으면 `SERVICE_CALL_PARTY_NOT_FOUND`, 고객 연결·새 고객을 함께 보내면 `SERVICE_CALL_PARTY_CUSTOMER_LINK`로 거절한다(D12를 서버에서도 지킨다). 같은 요청 id 재전송은 한 건 저장과 같이 이미 만든 콜을 돌려준다. 시각·메모가 같은지는 보지 않는다(D14상 시간은 사람별로 고친다). 인원 상한(10명)은 이 경로에서 검사하지 않는다. 두 화면이 동시에 더하면 같은 순번이 나올 수 있다(순번은 표시 순서라 막지 않았다).
