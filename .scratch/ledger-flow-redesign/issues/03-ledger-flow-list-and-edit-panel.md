# 03: 흐름별 원장 목록과 편집 패널

**What to build:** 원장 표(`editable-call-grid.tsx`)를 흐름별 한 줄 목록과 오른쪽 편집 패널로 바꾼다. 줄 끝 입장·결제 버튼, 칸마다 자동 저장하는 패널, 키보드 동선을 만든다. 보기 전환과 표 아래 새 행 입력을 없앤다. (스펙 D15–D22, D24)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 묶음: 지금 이용 중(사용중·종료 확인·청소중) → 예약 → 완료·취소·노쇼, 묶음 안은 예약시각순. 완료 묶음은 기본 접힘, "완료 N건"으로 펼치고 기기에 기억한다(저장소 실패 시 기본값).
- [ ] 한 줄: 시간 · 고객/메모 · 코스 · 매니저1(·2) · 객실 · 상태 칩·비고 · 경고/저장 아이콘 · 다음 할 일 버튼. 1280px·1024px에서 가로 스크롤이 없다.
- [ ] 입장: 실제입장 = 지금을 10분 단위로 맞춘 값, 상태 = 사용중. 객실이 비면 빈 객실만 보이는 선택 목록이 그 자리에서 열리고, 고른 뒤 저장한다. 낡은 저장 거절 규칙을 그대로 받는다.
- [ ] 결제: 패널의 결제 묶음이 열린다(결제수단 알약, 할인 구분, 계산된 결제금액, 관리자에게 수당). "결제 완료"가 상태를 방문완료로 저장한다.
- [ ] 패널 묶음: 예약(시간·코스·고객/메모·매니저1·2) / 입장(실제입장·객실·상태) / 결제 / 메모(비고) / 더 보기(방문별 요청·확인값·고객 연결 정정). 경고 전체와 관련 콜도 패널에 있다(기존 콜 상세 패널을 합친다).
- [ ] 패널은 칸마다 자동 저장한다. 저장 상태 다섯 가지, 낡은 저장 거절, 충돌 비교·다시 적용, 떠나기 안내가 지금처럼 동작한다(기존 `call-row-save` 계약 재사용).
- [ ] 키보드: ↑↓ 줄 이동, Enter 패널 첫 칸, Esc 목록 복귀(포커스가 그 줄로), N 빠른 예약. 입력칸 안에서는 단축키가 동작하지 않는다.
- [ ] 보기 전환이 없다. 주소의 `view`는 받아서 무시한다. 표 아래 "새 콜 행 추가"가 없다. 빠른 예약 저장 후 새 콜 줄이 선택되고 패널이 열린다.
- [ ] 운영월 잠금이면 버튼과 칸이 잠긴다.
- [ ] 깨지는 E2E(2-1, 2-2, 2-6, 티켓 13·15·16·17·18·19 등)는 새 동선으로 다시 쓴다. 지키던 계약(저장 무결성, 떠나기 안내, 경고)은 그대로 검증한다. 새 문구는 ko·vi.
