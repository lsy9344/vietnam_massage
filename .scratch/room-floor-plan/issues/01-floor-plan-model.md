# 01: 평면 배치 모델 — 좌표, 방→칸, 곧 비는 방, 흔든 선

**What to build:** 화면 없이 평면도를 그리는 데 필요한 순수 모듈을 만든다. "use client"가 없는 모듈(예: `src/modules/rooms/floor-plan.ts`)에 두고 단위 테스트로 굳힌다. (스펙 D1, D2)

**Blocked by:** 없음

**Status:** ready-for-agent

- [ ] 배치 데이터: 4층(`top`)과 1–3층(`std`) 좌표를 시안 `mockup/_shared.js`의 `PLAN.LAYOUTS` 값 그대로 둔다(가로 1165 × 세로 400, 방 칸, 복도, 엘리베이터, 칸막이).
- [ ] 방→칸: `RoomStatusDto[]`를 받아 층마다 칸과 방을 짝짓는다. 기준은 방 이름 앞 숫자(`roomFloorGroups`와 같은 규칙). 배치에 없는 방은 "기타"로, 방이 없는 칸은 빈 칸으로 돌려준다. 어떤 방도 빠지지 않는다.
- [ ] 한 줄 규칙: 상태별로 {종류, 라벨, 값}을 돌려준다(사용중·종료임박 → 남은 분, 0 미만은 0 / 예약 → 시작 시각 / 종료확인 → 할 일 / 청소중·빈방 → 없음). 문구는 화면 경계에서 번역하므로 여기서는 키나 숫자만 준다.
- [ ] 곧 비는 방: 빈방 전부 + 사용중·종료임박 중 남은 분 적은 순 3개. 남은 분이 같으면 방 순서로 안정 정렬한다.
- [ ] 흔든 선: 층 번호 씨앗의 결정적 난수로 벽·엘리베이터 경로(SVG `d` 문자열)를 만든다. 같은 입력이면 늘 같은 문자열이다(서버·클라이언트 렌더 일치).
- [ ] 단위 테스트(`tdd` 스킬): 방→칸(기본 11개, 번호 없는 방, 5xx 방, 빠진 방), 한 줄 규칙, 곧 비는 방 순서·개수, 흔든 선 결정성.
