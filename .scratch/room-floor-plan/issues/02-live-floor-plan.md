# 02: 실시간 화면 평면도와 방 서랍

**What to build:** `/live`의 객실판 격자를 평면도로 바꾼다. 방을 누르면 오른쪽 서랍에 지금 객실 카드가 뜬다. (스펙 D2, D3, D5)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 평면도 컴포넌트: 층 카드(층 이름 + 평면), 연필 벽 SVG, 엘리베이터·복도 이름, 방 이름표(번호, `StatusBadge` 작은 크기, 한 줄), 종료임박·종료확인 마커 고리. 시안 `mockup/c3-pencil.html`과 같게 보인다. 색·모서리·간격은 design.md 토큰과 클래스로만 쓴다(화면 코드에 색 값 금지).
- [ ] "지금 빈방 / 곧 비는 방" 줄(평면도 위)과 범례(평면도 아래, `aria-hidden`). 배치에 없는 방은 평면도 아래 "기타" 줄.
- [ ] 1200px 이상 2×2, 미만 1열. 좁은 칸은 컨테이너 쿼리로 기호만 둔다. 390px에서 가로 스크롤이 없다.
- [ ] 방 버튼과 빈방 칩을 누르면 `ModalPanel` 서랍에 `RoomStatusCard`(원장 링크는 지금 권한 그대로). Esc·덮개·닫기로 닫고 포커스를 누른 자리로 돌린다. 자동 갱신 뒤에도 열린 서랍이 새 값을 보이고, 방이 사라지면 닫힌다.
- [ ] ko·vi 문구(스펙 D5 표)를 더한다.
- [ ] 이 화면을 읽던 E2E·검증 스크립트(스펙 "객실판을 읽는 기존 스펙·검증기")를 평면도에 맞게 고치고, 새 E2E로 방 서랍 열기·닫기·포커스 복귀와 빈방 칩을 확인한다(다른 스펙과 겹치지 않는 날짜를 쓴다).
