# 06: 휴무 신청과 승인함

**What to build:** Therapist가 근태 탭에서 앞으로의 날짜에 휴무를 신청하고, 관리자와 정산 담당이 새 승인함에서 승인하거나 거절한다. 승인되면 그날 근무 예정이 휴무가 된다. 승인함은 07의 정정 요청도 받을 수 있는 모양으로 만든다. (스펙 D22, D24, D28)

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Therapist는 앞으로의 날짜에만 신청한다. 이미 휴무인 날과 이미 신청 중인 날은 거절한다. 사유는 선택이다.
- [ ] 승인 전에는 Therapist가 취소할 수 있다. 처리되지 않은 채 날짜가 지나면 "기한 지남"으로 닫힌다.
- [ ] 승인함은 운영팀 화면이고, 근무표를 고칠 수 있는 관리자와 정산 담당만 연다. 대기 중인 신청이 위에 온다. 승인함의 대기 건수를 도크나 메뉴에서 알 수 있다(`design.md`를 따른다).
- [ ] 승인하면 기존 근무표 서비스로 그날이 휴무가 된다. 승인 화면에는 그날 그 Therapist에게 배정된 예약 수가 보이지만, 승인을 막지는 않는다.
- [ ] 거절할 때는 사유가 필수다. 결과와 사유는 Therapist의 근태 탭 그 날짜에 보인다.
- [ ] 승인과 거절이 감사에 남는다.
- [ ] 신청을 저장할 표를 더하기만 하는 마이그레이션으로 만든다. 운영 DB 적용은 사용자 확인 뒤에 한다.
- [ ] 새 문구는 ko·vi 두 언어로 있다.
- [ ] 단위 테스트, tsc, E2E가 통과한다. E2E는 신청 → 승인 → 근무표 휴무 → 근태 탭 표시를 확인한다. 카운터 역할이 승인 액션을 직접 부르면 거절되는지도 확인한다.
