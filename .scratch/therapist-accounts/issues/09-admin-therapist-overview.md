# 09: 관리자 Therapist 현황

**What to build:** 관리자가 한 화면에서 오늘 누가 어떻게 출근했는지와, 이번 달 사람별 근태 집계, 대리 입력 횟수, 완료 콜 수와 순위를 본다. 근태 판정은 04의 계산을 그대로 쓴다. (스펙 D26)

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 관리자만 연다.
- [ ] 오늘 영역에는 활성 Therapist마다 출근 여부, 출근·퇴근 시각, 찍힌 방식(직접, 대리 입력, 정정 승인)이 보인다. 지각, 퇴근 미입력, 예정 없는 출근이 표시된다.
- [ ] 이번 달 영역에는 사람별로 아래 내용이 보이고, 운영월을 고를 수 있다.
  - 지각 횟수와 합계 분
  - 결근
  - 퇴근 미입력
  - 예정 없는 출근
  - 대리 입력 횟수(이전 기록은 세지 않음)
  - 완료 콜 수(방문완료)와 순위
- [ ] 숫자는 04 판정과 정산 완료 건수와 같다. 이 화면만의 계산을 따로 만들지 않는다.
- [ ] 화면 모양은 `design.md`를 따르고, 자동 새로고침은 하지 않는다.
- [ ] 새 문구는 ko·vi 두 언어로 있다.
- [ ] 단위 테스트, tsc, E2E가 통과한다. E2E는 정산 담당과 카운터가 이 화면에 들어갈 수 없는지 확인한다.
