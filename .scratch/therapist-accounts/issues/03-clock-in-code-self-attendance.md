# 03: 출근 코드와 직접 출퇴근, 찍힌 방식

**What to build:** 매장 화면에 1분마다 바뀌는 4자리 출근 코드를 띄우고, Therapist가 "오늘" 탭에서 그 코드를 넣어 직접 출근·퇴근을 찍게 한다. 출근과 퇴근 각각에 찍힌 방식(직접, 대리 입력, 정정 승인)을 남긴다. (스펙 D13–D16, ADR 0009)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 출근 코드는 서버 비밀값과 시각에서 계산하는 4자리 숫자이고, 1분마다 바뀐다. 코드를 띄우는 화면에는 그날만 쓰는 키만 내려 주고, 화면이 시각으로 코드를 계산한다. 코드를 띄우려고 DB를 주기적으로 읽지 않는다.
- [ ] TV 현황판 구석에는 출근 코드가 항상 보인다. 영업시간 밖에도 보인다. 카운터와 관리자는 "출근 코드" 버튼으로 크게 띄울 수 있다.
- [ ] Therapist는 "오늘" 맨 위의 출근·퇴근 버튼을 누르고 코드를 넣는다. 서버는 지금 코드와 직전 1분 코드를 받는다.
- [ ] 틀린 코드를 5번 넣으면 그 Therapist는 15분 동안 코드를 넣을 수 없고, 남은 시간이 보인다.
- [ ] 출근과 퇴근은 운영일마다 한 번씩이다. 이미 찍었으면 버튼이 정정 요청 안내(07)로 바뀐다. 밤샘 퇴근, 잠긴 운영월 거절, 만근 판정은 기존 출퇴근 서비스를 그대로 쓴다.
- [ ] 휴무인 날이나 근무 예정이 입력되지 않은 날에도 찍힌다. 그 기록을 예정 없는 출근으로 알아볼 수 있다.
- [ ] 출퇴근 기록에 출근 방식과 퇴근 방식 칸을 더한다. 값은 직접, 대리 입력, 정정 승인, 이전 기록 넷이다. 기존 출퇴근 화면에서 운영팀이 저장한 시각은 대리 입력이 되고, 이 칸이 생기기 전의 기록은 이전 기록이다. 더하기만 하는 마이그레이션이고, 운영 DB 적용은 사용자 확인 뒤에 한다.
- [ ] 직접 찍기와 대리 입력이 감사에 남는다.
- [ ] 새 문구는 ko·vi 두 언어로 있다. 390px에서 가로 스크롤이 0이다.
- [ ] 단위 테스트로 코드 계산(경계 분, 직전 1분 허용, 다른 날 키 거절)과 실패 잠금을 확인한다. E2E는 TV에 보인 코드로 출근 → 퇴근을 확인하고, 틀린 코드 5번 뒤 잠기는지도 확인한다.
