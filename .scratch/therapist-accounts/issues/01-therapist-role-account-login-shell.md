# 01: Therapist 역할, 계정 발급, 로그인, 빈 Therapist 화면

**What to build:** `therapist` 역할을 더하고, 관리자가 직원 화면에서 Therapist 계정을 발급하고 초기화하고 정지할 수 있게 한다. Therapist가 로그인하면 첫 비밀번호를 바꾼 뒤 네 탭짜리 빈 Therapist 화면으로 간다. 운영팀 화면과 서버 액션은 모두 거절한다. (스펙 D1–D9, D28, D29)

**Blocked by:** 없음

**Status:** ready-for-agent

- [ ] 역할 목록에 `therapist`를 더한다. 이 역할은 민감 권한이 없다. 역할별 첫 화면은 Therapist 화면이고, `screenRoutes`의 운영팀 화면(TV 포함)에는 들어갈 수 없다.
- [ ] 직원 구분이 Therapist인 직원에게만 `therapist` 역할을 줄 수 있고, 그런 직원에게는 이 역할만 줄 수 있다. 어기면 서버가 거절한다.
- [ ] 관리자는 직원 화면의 Therapist 패널에서 계정을 발급한다. 계정 ID 기본값은 직원 코드다. 발급 직후 인쇄할 수 있는 베트남어 안내 쪽지가 뜬다. 쪽지에는 접속 주소 QR, 계정 ID, 임시 비밀번호가 들어간다. QR에 새 의존성이 필요하면 Cloudflare 배포에서 도는 작은 순수 JS 라이브러리 하나만 더한다.
- [ ] 관리자는 비밀번호 초기화(새 임시 비밀번호와 쪽지)와 계정 정지를 할 수 있다. 기존 잠금 해제도 그대로 쓴다.
- [ ] 발급이나 초기화 뒤 첫 로그인에서는 비밀번호를 바꾸기 전에 다른 화면으로 갈 수 없다. 기존 `changePassword`를 쓴다.
- [ ] Therapist 계정은 30일 동안 다시 로그인하지 않아도 된다. 운영팀 계정의 로그인 유지 시간은 바뀌지 않는다.
- [ ] 직원 상태를 퇴사로 바꾸면 연결된 Therapist 계정이 정지되고 감사에 남는다. 이미 로그인한 세션도 다음 요청에서 막힌다. 휴직은 그대로 둔다.
- [ ] Therapist 화면은 운영팀 도크 없이 아래 탭 **오늘, 근태, 수당, 공지**를 둔다. 오른쪽 위 "나" 메뉴에는 언어, 비밀번호 변경, 로그아웃이 있다. 탭 내용은 비어 있다(02–08). 처음 언어는 베트남어다.
- [ ] Therapist 화면은 자동 새로고침을 하지 않는다. 열 때, 돌아올 때, 새로고침 버튼으로만 읽고, 마지막 갱신 시각을 보인다. 이 동작은 공통 조각으로 두어 02–08이 쓴다.
- [ ] 계정 발급, 초기화, 정지, 자동 정지가 감사에 남는다.
- [ ] 새 문구는 ko·vi 두 언어로 있다. 루트 `design.md`를 따른다. 390px 폭에서 가로 스크롤이 0이다.
- [ ] 단위 테스트, tsc, E2E가 통과한다. E2E는 발급 → 첫 로그인 → 비밀번호 변경 → 빈 Therapist 화면을 확인한다. therapist 역할로 운영팀 화면과 서버 액션을 직접 호출하면 거절되는지도 확인한다.
- [ ] `UserAccount`에 칸이 필요하면(첫 비밀번호 변경 표시 등) 더하기만 하는 마이그레이션으로 만든다. 운영 DB 적용은 사용자 확인 뒤에 한다.
